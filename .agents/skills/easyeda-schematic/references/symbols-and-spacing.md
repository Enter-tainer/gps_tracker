# 符号几何与间距（实测）

来源：`exp-symbol` 子任务实测，20 个器件全部精确命中，`lib_Symbol.getGeometry()` 全部返回有效几何；
并用「临时页真实放置 + `getAllPinsByPrimitiveId` 读绝对坐标」交叉验证 **31/31 脚误差为 0**。

单位 **1 = 0.01 inch = 10 mil = 0.254 mm**。`getGeometry` 的 `pins[].x/y`、`fullBBox`、`bodyBBox`
**可直接与放置锚点相加，不需要翻 Y 轴**。

## 间距

严格公式（锚点不在 bbox 中心时**必须**用它）：

```
水平：b.x - a.x >= A.fullBBox.maxX - B.fullBBox.minX
竖直：a.y - b.y >= B.fullBBox.maxY - A.fullBBox.minY
```

同款相邻化简为「中心距 ≥ 宽（或高）」。建议留 10 单位走线：

| 器件 | 水平间距 | 竖直间距 |
| --- | --- | --- |
| TYPE-C-16PIN | 110 | 140（含 EH 区） |
| TP4056 | 110 | 70 |
| USBLC6 | 100 | 50 |
| RT9080 | 90 | 50 |
| AO34xx | 45 | 50 |
| SS14 | 50 | 26 |
| LED-0603 | 50 | 37 |
| 阻容 | 50 | 20–31 |
| 端子 2P / SS-12 | 40 / 40 | 40 / 95 |

`100` 是「刚好相切」，电气上不算重叠，但没有走线空间。

## 三个必记特例

1. **TYPE-C-16PIN**：`full [-50,-60]→[50,70]`；左列 8 脚 x=−50、右列 8 脚 x=+50，
   顶上 `EH` 在 `(0,+70)`。中间 6 段引脚间距只有 10，是最密的一处；上方必须额外留 EH 区。
2. **TP4056**：左 4 右 5；**EP（脚 9）不在底部，而在右侧最上 y=+20，与 CE 只隔 10**。
   按「散热盘在底下」排会完全对不上；CE 建议先右引再折，避开 EP 的地。
3. **半格坐标**：`SS-12F45G4-RS` 上下脚 `x=+5`，`2P-P3.81` 两脚 `y=±5`。
   连线端点必须用**原始坐标**，四舍五入会把端点打散、连不上。
