## 打印建议

这台设备的原始外壳是在 Bambu Studio 里做的，下面的参数是保守的通用起点，不是原作者的实测值：

| 参数 | 建议 |
| --- | --- |
| 材料 | PETG（户外使用更耐晒、韧性好）或 PLA+ |
| 层高 | 0.20 mm |
| 墙数 | 3 层 |
| 顶部/底部实心层 | 4 / 3 层 |
| 填充 | 15–20%，网格或螺旋 |
| 支撑 | 按切片预览决定；模型已按打印姿态导出，**不要自动旋转或自动摆放** |
| 打印方向 | 大平面朝下（底壳开口朝上），减少支撑 |

导入步骤（Bambu Studio / Orca）：

1. 直接打开 `case-slim-v1.3mf`——3MF 会按原装配位置把 3 个实体分别摆在盘上；
2. 若用 STL，则逐个拖入 `part-1` / `part-2` / `part-3`，并保持原有坐标关系（不要「自动摆放」打乱相对位置）；
3. 切片前确认天线区域上方没有加厚壁厚或金属嵌入件（陶瓷天线对金属和厚塑料敏感）。

## 装壳注意事项

- **先焊后装**：PCB 全部元件（尤其 OLED、两个按键、TF 卡座）焊完并通电自检通过后再装壳，返工要拆壳很麻烦。
- **按键高度**：`URST` / `UUSR` 是贴片轻触键，装壳后要能按到，键帽高度不合适时优先在壳内加垫片或换同尺寸加高键帽。
- **天线净空**：陶瓷天线一侧尽量朝向壳体开口 / 薄壁方向，不要贴着电池或金属件。
- **电池**：21700 电芯先点焊镍片或装电池座，确认极性无误再上电；首次上电建议串限流。
- 若外壳是卡扣结构，反复拆装会松，可在卡扣处点少量 UV 胶或热熔胶（不要把排水/散热缝全堵死）。
