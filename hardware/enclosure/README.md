## 打印建议

两款外壳均在 Bambu Studio 中设计，下面是通用的起点参数：

| 参数 | 建议 |
| --- | --- |
| 材料 | PETG（户外耐温耐晒、韧性更好）或 PLA+ |
| 层高 | 0.20 mm |
| 墙数 | 3 层 |
| 顶部/底部实心层 | 4 / 3 层 |
| 填充 | 15–20%，网格或螺旋 |
| 支撑 | 按切片预览决定；Slim 版请勿自动打乱 3 零件相对位置；21700 版可竖直或大面朝下摆放 |

导入步骤（Bambu Studio / Orca Slicer）：

1. 直接打开对应的 `.3mf` 文件（`case-slim-v1.3mf` 或 `case-21700-v1.3mf`），或导入 `.stl`；
2. 切片前确认陶瓷天线区域上方没有加厚壁厚或金属嵌入件（陶瓷天线对金属和厚介质敏感）。

## 装壳注意事项

- **先焊后装**：PCB 全部元件（尤其 OLED、两个按键、TF 卡座）焊完并通电自检通过后再装壳。
- **电池方案匹配**：
  - 装 **Slim 壳**：PCB 背面**不焊 `U8` 电池座**，软包薄锂电池直接贴在 PCB 背面空间内并插入 `CN2`（注意核对 1.25 mm 线序正负极）。
  - 装 **21700 壳**：焊接 `U8` 电池座并装入单节 21700 电芯，确认极性无误再上电。
- **按键高度**：`URST` / `UUSR` 是贴片轻触键，装壳后要能从外壳键位按到，键帽高度不合适时优先在壳内加垫片或换同尺寸加高键帽。
- **天线净空**：陶瓷天线一侧尽量朝向壳体开口 / 薄壁方向，不要贴着电池或金属件。
- 若卡扣或端盖反复拆装后变松，可在边缘点少量 UV 胶或热熔胶固定。
