## 1. 电源架构

```
BAT1 1500mAh 软包（带保护板）
 ├─ B+ ──┬─ VBAT ─→ M1.B+ / M1.RAW（主控 + 充电输入）
 │       ├─ VBAT ─→ U1.RT9080N.VIN / EN
 │       ├─ VBAT ─→ Q1.S（电量采样高边）
 │       └─ VBAT ─→ R4 10k → Q1.G
 └─ B− ───────────→ GND

U1 RT9080N-33GJ5（常开，Iq 2µA typ / 4µA max）── 3.3V_AON
 ├─ U2A / U2B 加速度计（VDD + VDD_IO + CS + SA0）
 ├─ U4 L76K.V_BCKP（经 R1 100Ω）
 ├─ U3 W25Q128 VCC（深度休眠 1µA typ）
 └─ 上拉 R2/R3（ACC I²C）、R10/R11/R12（Flash）

M1.5 = 模块板载 LDO 输出（P0.13 门控）── 3.3V_SW
 ├─ U4 L76K.VCC
 ├─ J2 OLED.VCC
 └─ R8/R9（OLED I²C 上拉）

GPS_EN (M1.P1.13) ──→ U4.pin5 WAKEUP
GPS_RST (M1.P0.02) ──→ U4.pin9 RESET_N
```

### 1.1 三种供电状态

| 场景 | 3.3V_SW (P0.13) | GPS_EN | 说明 |
| --- | --- | --- | --- |
| 深睡 / 屏灭待机 | **关** | 低或高阻 | GPS 落备份域（V_BCKP 8µA），热启动不丢星历 |
| 操作 / 亮屏 | 开 | 低（standby 20µA） | OLED 工作，GPS 待命 |
| 追踪记录 | 开 | 高（连续 29mA） | GPS 连续定位，Flash 记录 |

> 屏灭待机**直接关 P0.13**，不要用「3.3V_SW 开着 + GPS standby」——后者要付 WAKEUP 上拉（50~600µA）+ 模块 LDO Iq。

### 1.2 功耗账

**S_deep（P0.13 低、GPS 落备份域、System OFF）**

| 轨 | 项 | typ | max | 依据 |
| --- | --- | --- | --- | --- |
| 3.3V_AON | U1 RT9080N Iq | 2.0µA | 4.0µA | 手册 |
| | U1 SNS 内部链路 | 0.55µA | 0.55µA | §8 第 4 条 |
| | W25Q128 DPD | 1.0µA | **20µA** | 若没进 DPD：10/60µA |
| | U2B LIS3DHTR LP 1Hz | 2.0µA | 4µA（无规格，按 2×） | LIS3DH **无 1µA 档** |
| | GPS V_BCKP（经 R1） | 8.0µA | 8.0µA（手册无 max） | 手册 |
| | 电容漏电 | 0.05µA | 0.2µA | IR ≥500MΩ·µF |
| | **AON 小计** | **13.6µA** | **34.8µA** | |
| VBAT | 采样链（EN 低，25℃） | 0.15µA | 2.0µA | AO3401/3400 IDSS |
| | 采样链（55℃ 上限） | 0.15µA | **10µA** | Q1 的 IDSS 5µA + Q2 的 IDSS 5µA（手册 55℃ 测试点）；R4=10k 使 Q2 漏电只把 Q1 栅压抬 50mV，Q1 不会开启 |
| 模块 | 自身静态（好批 / 标称 / 坏批） | 4µA | 60µA | 社区实测 + 厂商 |
| | 内部电池分压（P0.24，电阻 NC） | 0 | 0（若贴了 ~210µA） | 来料核对 |
| **整机 S_deep** | | **≈18µA** | **≈110~130µA** | |

> **电芯账本**还要再加：保护板 3µA + 自放电等效 21~42µA（在 J1 之内、电流表之外）。
> 对外标称写「AON 支路 13.6µA typ + 模块自身 ~4µA」，不要写「深睡 12µA」。

> **两种"深睡"必须分开算**（这是模块功耗差 10 倍的地方）：
> - **System OFF**（GPIO DETECT 唤醒，RAM 不保留，唤醒=复位）：nRF52840 高压模式 **0.95µA**，加上模块板级（充电 IC 反灌 ≤2 + LDO 关断 0.1 + 10M 上拉 0.42 + 肖特基漏 ~0.4）≈ **4µA**。上表的 4µA 指这一档。
> - **System ON + WFI + RTC**（保留 RAM、定时唤醒、**可继续 BLE 广播**）：nRF 自身约 3µA，但**整模块实测约 50µA**（板级 LDO/充电器/上拉等叠加）。若产品需要在睡眠期间保持 FindMy/周期广播，**不能进 System OFF**，预算按这一档：整机 ≈ **65~75µA**。
> 选哪一档取决于产品行为，不是纯硬件问题——**这是 §1.1 里"S_deep"唯一需要提前拍板的定义**。

**S_on（3.3V_SW 开、GPS standby、屏灭）**

| 项 | typ | max |
| --- | --- | --- |
| AON 支路 | 13.6µA | 34.8µA |
| 模块板载 LDO（ME6217）Iq | 100µA | 待实测（另有 1µA 说法，差 100 倍） |
| GPS standby | 20µA | 20µA |
| WAKEUP 内部上拉灌入 MCU | 50µA | 600µA |
| OLED 模块静态 | 10µA | 100µA |
| 模块自身 | 4µA | 60µA |
| **合计** | **≈0.19mA** | **≈0.83mA** |

**S_gps（连续定位）≈ 35mA**：GPS 29 + MCU 活跃 2~6 + Flash 写峰值 25mA（占空比低）+ OLED 按需。

**首板验收判据**（µA 表）：
- AON 支路 S_deep **13~14µA** 正常；**22µA** ⇒ Flash 停在 ICC1（没进 DPD）；**>300µA** ⇒ 有引脚被驱动低。
- 3.3V_SW 在 P0.13 拉低后 **<100mV** 且保持 ≥100ms。

### 3.2 U1 — RT9080N-33GJ5（TSOT-23-5）

| 脚 | 网络 | 备注 |
| --- | --- | --- |
| 1 VIN | VBAT | + C1 10µF 到 GND |
| 2 GND | GND | |
| 3 EN | VBAT | 直接短接 VIN（常开，不可悬空） |
| 4 **SNS/NC** | **3.3V_AON** | **一律接 VOUT**：N 版是 SNS（接 VOUT 才闭环；悬空或接 GND 会让输出冲到 ≈VIN）；非 N 版是 NC（接 VOUT 无电流）。线短粗，接 C2 正端 |

### 3.3 电量采样（Q1 + Q2）

| 器件/脚 | 网络 |
| --- | --- |
| Q1.S (pin2) | VBAT |
| Q1.G (pin1) | Q1_G |
| Q1.D (pin3) | ADC_HI |
| R4 | VBAT — Q1_G |
| Q2.D (pin3) | Q1_G |
| Q2.G (pin1) | BAT_ADC_EN |
| Q2.S (pin2) | GND |
| R7 | BAT_ADC_EN — GND |
| R5 | ADC_HI — BAT_ADC |
| R6 | BAT_ADC — GND |
| C9 | BAT_ADC — GND |

`BAT_ADC_EN` 高 → Q2 通 → Q1 栅极拉低 → Q1 通 → VBAT 经 R5/R6 分压到 BAT_ADC；拉低后 Q1 关断，分压链无回路（I_DSS 典型 <0.1µA，规格上限 2µA@25℃ / 10µA@55℃）。

**建立时间**：R5‖R6 = 100kΩ，C9 100nF → τ = 10ms；12bit 精度需约 **9τ ≈ 90ms**。

### 3.4 加速度计（U2A / U2B，二选一）

两套焊盘并排、共享信号，**两颗 SA0 都接 3.3V_AON（同址 0x19）**，只装一颗。**首板装 U2B（LIS3DHTR）**——库存件且固件（`lis3dh` crate）只支持它。

| 信号 | U2A：LIS2DW12TR（LGA-12） | U2B：LIS3DHTR（LGA-16） |
| --- | --- | --- |
| SCL | 脚1 ← ACC_SCL | 脚4 ← ACC_SCL |
| SDA | 脚4 ↔ ACC_SDA | 脚6 ↔ ACC_SDA |
| CS（I²C 模式） | 脚2 → 3.3V_AON | 脚8 → 3.3V_AON |
| **SA0（地址）** | 脚3 → 3.3V_AON（0x19） | 脚7 → 3.3V_AON（0x19） |
| INT1 | 脚12 → ACC_INT1 | 脚11 → ACC_INT1 |
| INT2 | 脚11 → ACC_INT2 | 脚9 → ACC_INT2 |
| VDD | 脚9 → 3.3V_AON | 脚14 → 3.3V_AON |
| VDD_IO | 脚10 → 3.3V_AON | 脚1 → 3.3V_AON |
| GND | 脚6 / **脚7 RES 必须接 GND** / 脚8 | 脚5 / **脚10 RES 必须接 GND** / 脚12 |
| 退耦 | C5 100nF + C10 10µF 紧贴脚9 | 共用 C5 + C10 |

> **SA0 不能接 GND**：内部上拉不可关（手册未给阻值，3.3V 约 20~22kΩ），接 GND 会持续漏 ~150µA。
> 两颗同址后用 **WHO_AM_I** 区分（LIS2DW12 = 0x44，LIS3DH = 0x33；注意 0x33 同时也是 SA0=1 的读地址字节）。
> ⚠ **两颗都装会彻底不可用**：同址导致双 ACK + SDA 线与，WHO_AM_I 读回 0x00，两颗都被判成"无器件"。**装配必须二选一。**

## 5. 固件约束

1. **GPS_EN 极性**：低 = standby（20µA），高/释放 = 连续（**电平型，非边沿**）。3.3V_SW 上电前 P1.13 保持高阻（内部上拉 → 连续，安全），模块稳定后再切输出。
2. **关 3.3V_SW 前必须把 6 根脚高阻化**：`GPS_EN`(P1.13)、`GPS_RST`(P0.02)、`GPS_TX`(P0.06)、`GPS_RX`(P0.08)、`OLED_SCL`(P0.11)、`OLED_SDA`(P1.04)。
   - 高阻化 = `Dir=Input` + `Input=Disconnect` + `Pull=Disabled` 三件事。⚠ `drop(Uarte)`/`drop(Twim)` **不还原引脚方向**（embassy-nrf 0.11 `deconfigure_pin()` 只关输入缓冲）→ 必须显式配置或写 PIN_CNF。
   - `GPS_EN`/`GPS_RST` 是低有效 + 目标内部上拉 → 只在「输出低 ↔ 输入断开」之间切换、**永不输出高**，这两根结构上不可能倒灌；OLED 只走 TWIM（开漏），禁止 bit-bang 与内部上拉。
   - **`GPS_TX` 没有串阻，没有硬件兜底**：必须 `deinit` UARTE0 并置高阻，否则 3.3V 经 ESD 二极管灌进 3.3V_SW，轨被钉在 ~2.8V、GPS 得不到干净复位。
3. **GPS 初始化双波特率探测**：standby 唤醒不丢配置（core/IO 仍供电），只有 3.3V_SW 断电后才可能回默认。断电恢复先试 115200，2s 无响应回 9600 重发 `$PCAS04`→`$PCAS03`→`$PCAS01`→`$PCAS02`；standby 唤醒跳过重配。
4. **W25Q128 深度休眠**：
   - 进：/CS 低 → `0xB9` → 第 8 bit 后拉高 /CS → 3µs 内进入；
   - 出：**必须先发 `0xAB`**，/CS 保持 ≥`tRES1` 3µs；只等待不会退出；
   - **进 DPD 前必须等 BUSY=0**：擦写中除读状态外指令全被忽略，`0xB9` 被静默丢弃（不坏数据，但没睡，停在 ICC1 60µA max 而非 DPD 20µA max）；
   - 上电（或非 DPD 下软复位）后默认待机 10µA；**DPD 中 66h/99h 被忽略，复位不能退出 DPD**；DPD 跨 MCU 复位存活 → 驱动初始化第一步无条件发 `0xAB`；
   - **只允许 1-1-1 标准指令**（本硬件 Dual 也不可能：SPIM 的 MOSI/MISO 单向）。禁止 `32h`/`6Bh`/`EBh`/`77h`/`94h`/`3Bh`/`BBh`/`92h`。QE 固定=1 意味着器件侧接受这些指令，而 IO2/IO3 未接 MCU 又被 10k 拉高 → 发 `32h` 会写坏一半数据位，属静默坏数据；
   - **JEDEC ID = `EF 40 18`**（JVSIQ/JQ）；JVSIM/JM 是 `EF 70 18`。
5. **进 System OFF 前**：SPI 引脚置高阻（R10 已保证 /CS 为高）；写完再睡，擦写中途断电会损坏扇区。
6. **加速度计**：两颗地址都是 0x19，用 WHO_AM_I 区分。
   - `P1.15`(INT1) **禁止开内部上拉**（传感器推挽输出，开 13k 会灌 254µA）；latched 中断睡前必须清 latch，否则 DETECT 常有效 → 唤醒风暴；睡前关掉其它脚的 sense（PORT/DETECT 是整端口 OR）。
   - LIS2DW12 禁用 single-data-conversion-on-demand 与 SLP_MODE_SEL=0（该模式下 INT2 变时钟输入，而 INT2 悬空）。
   - I²C 上限 400kHz（4.7k 上拉只对 ≤75pF 总线成立）。
7. **GPS 软件复位**：`GPS_RST` 平时高阻输入；无响应时拉低 **≥100ms** 再释放。
8. **P0.13 拉低 = 3.3V_SW 断电**。深睡顺序：停 GPS → 关 OLED → 6 脚高阻/驱动低 → 拉低 BAT_ADC_EN → 拉低 P0.13 → System OFF。
9. **WAKEUP 内部上拉漏电需实测**：手册未给阻值，姊妹型号标称「拉低到地 standby 约 600µA」，亮屏待机可能在 0.1~0.6mA。
10. **待机策略**：屏灭直接关 P0.13；GPS_EN 只在「3.3V_SW 必须开着」时用于单独关 GPS。
11. **电量采样**：`BAT_ADC_EN` 拉高后**至少等 90ms** 再采，采完立即拉低；分压系数 **2.0**（200k/200k）；SAADC 用 0.6V 内参 / GAIN1_6。
    - EN 高时整链常耗 ≈ 85µA（R7 33 + R4 42 + 分压 10.5）；
    - **进 System OFF 前必须显式拉低**（System OFF 期间 GPIO 配置保持）；
    - **采样周期 ≥30s**，或只在唤醒/上传前采。
12. **L76K 下电时序（无泄放电阻）**：手册要求 VCC 掉到 <100mV 并保持 ≥100ms 才完成掉电复位。
    - 日常 GPS 开关走 `GPS_EN`（standby），**不断 3.3V_SW**；
    - 断轨只在深睡发生；轨上 11~21µF 靠漏电放完要 **3.5~127s**（断轨 1s 后仍在 2.4~3.2V）；
    - **正确做法**：断轨后把 6 根 MCU→外设脚**驱动「低」**（不是高阻）——`OLED_SCL/SDA` 拉低后模块 10k 上拉（与 R8/R9 并联）成为泄放 → 轨 **60~190ms** 到 100mV，同时零倒灌；`GPS_RX` 例外，保持输入无上拉；
    - 唤醒后**先释放这些脚再让 P0.13 起来**，并在 I²C 初始化前做 9 时钟 bus-clear。
13. **外设实例互斥**：本设计需 2×TWIM + 1×SPI。`SPIM0/TWIM0`、`SPIM1/TWIM1` 是同一实例 → W25Q128 只能用 **SPIM2（推荐，8MHz ≈ 1MB/s）** 或 SPIM3（32MHz ≈ 4MB/s，但需 Errata 198 workaround，且 Errata 195 与深睡预算冲突）。**QSPI 物理不可用**（模块未引出 P0.19/21/23）。v1 的 `SPI3` 不能照搬。
14. **睡前把相关引脚设成高阻**（`nrf_gpio_cfg_default()`：输入、无上下拉）。System OFF 期间 PIN_CNF 保持：
    - `P1.06`(SPI_CS) 输出低 → 330µA；内部下拉 → 143µA
    - `P1.00/P0.24`(ACC I²C) 输出低 → 702µA/根；内部下拉 → 186µA/根
    - `P1.15` 例外：输入 + 无上下拉 + `SENSE=High`
    - 睡前做一次 I²C bus-clear（9 SCL + STOP），防从机拉死 SDA
15. **加速度计档位**：深睡用 **LP ODR=1Hz（2µA）**，需要更快响应用 10Hz（3µA）。**禁止 HR 50Hz（11µA）**；LIS3DH 没有 1µA 档。
16. **LFCLK 用外部晶振**：模块板上有 32.768kHz 晶振（Y2），当前固件用内部 RC（500ppm）→ 改 XTAL 后 MPSL 精度可降到 ~40–50ppm，广播窗口缩短。
17. **BLE 广播间隔**：100ms ≈ 60µA、500ms ≈ 15µA、1s ≈ 9µA、2s ≈ 6µA。建议 ≥1s。
18. **System OFF 入口清单**：停 UARTE0/TWIM/SPIM/SAADC/TIMER/RTC/NFCT，关 USBD 与 VBUS 检测，等 EasyDMA 完成，`RAM[n].POWER=0`（放弃 RAM 保留）；唤醒源只用 **GPIOTE PORT/DETECT**（绝不用 IN event：17.37µA vs 2.36µA）；只给 `P1.15` 和 `P1.11` 开 sense；实测须断开调试器（否则 System OFF 被模拟）。
19. **唤醒后的引脚态**：CPU 唤醒 = 复位，但 `PIN_CNF` 是 retained register（需实测确认）。**无论哪种结果，启动最早期必须显式建立全部引脚安全态，不得依赖复位默认值。**

## 8. 手册依据（关键条目）

1. **LIS2DW12**：SDO/SA0 内部上拉不可关闭（手册未给阻值，3.3V 约 22kΩ），接 GND 持续漏 ~140µA，掉电电流仅 50nA → 接 3.3V_AON；退耦 100nF + 10µF 紧贴 pin9；`RES(pin7) 必须接 GND`；INT1/INT2 默认推挽、不可加上拉。
2. **LIS3DHTR**：SA0 接 3.3V_AON = 0x19（内部上拉不可关，接 GND 估计漏 ~150µA）；VDD 与 VDD_IO 均接 3.3V_AON；`RES(pin10) 必须接 GND`。
3. **W25Q128JV**：DPD 1µA typ / 20µA max、待机 10µA typ / 60µA max；/CS 上电期须跟随 VCC；DPD 退出必须先发 `0xAB`；`Q` 后缀 QE 固定=1 → pin3/pin7 为 IO2/IO3；JV 无 QPI 指令；`S` = SOIC-8 208mil。
4. **RT9080 / RT9080N**：EN 不可悬空、可直连 VIN；输出电容「有效 ≥1µF」无上限；Iq 2µA typ / 4µA max；dropout 0.31V@600mA。**pin4**：非 N 版为 NC，N 版为 SNS（必须接 VOUT，内部链路 550nA，SNS 电位 = 该料号标称 VOUT）。
5. **L76K**：VCC 2.7–3.4V、连续 29mA、standby 20µA、backup 8µA；WAKEUP 低有效进 standby；RESET_N 内部上拉、禁止外加上拉；**V_BCKP 不得晚于 VCC 上电**；推荐 V_BCKP 4.7µF + 100nF + 33pF；无源天线直连不需隔直电容；RESERVED 必须悬空；SET 是星座选择。
6. **ProMicro（nologo）**：P0.13 低 → 关断 3.3V/VCC；BOOST 短接 → 充电 100→300mA（电池须 >500mAh）；待机 ~20µA；电池接口 B+/B−。

| **V_BCKP 架构上不可断电** | R1 直连 AON，8µA 是硬地板（年耗 62.5mAh ≈ 电池 4.2%），换来热启动 |
| **J1 无反接保护** | JST 有防呆槽，但引线极性取决于压接；接反则 U1 VIN 承受负压而损坏 |
| **L76K 断电下降速率** | 手册要求 <50ms 到 100mV，无泄放时达不到；靠"深睡后早已放净"规避 |

### 9.4 低电量策略

3.3V_AON 在电池 < ~3.32V 时随电池跌落，而 **W25Q128 最低工作电压 2.7V**：

- 电池 < **2.85V**：禁止开 GPS/OLED 高负载（3.3V_SW 已逼近 L76K 的 2.7V 下限）
- 电池 < **2.75V**：禁止 flash 擦写并停止记录，避免半写损坏扇区
- 硬件级兜底：`SR1.BP[2:0]=111`（全片保护）+ `SRP=1`（锁定 SR 不可改），在电压跌落前先行写入
