> 本文件是 v2.1 的**唯一设计依据**。它修正了 v2.0 初稿中的三处错误（见 §0.2），

## 0. 相对 v2.0 初稿的变更

### 0.1 架构变更

| 项 | v2.0 初稿 | v2.1 最终 |
| --- | --- | --- |
| 主控 | nRF52840 ProMicro（不变） | 同，**沿用 v1 的 26 pad 符号** |
| 常开轨 | RT9080 → 加速度计 + GPS 备份域 | **再加 W25Q128**（深度休眠 1µA） |
| 开关轨 3.3V_SW | GPS + OLED + W25Q128 | **GPS + OLED**（flash 移走） |
| GPS 关断 | 悬空，靠 3.3V_SW 整条断电 | **新增 GPS_EN → L76K pin5(WAKEUP)**，常态 29mA→20µA |
| 3.3V_SW 用途 | 常态省电 + 深睡 | **深睡/屏灭待机**（见 §1 状态表与 §5-8） |

**为什么这样分工**（关键，别搞混）：

| 场景 | 3.3V_SW (P0.13) | GPS_EN (WAKEUP) | 电流 |
| --- | --- | --- | --- |
| 追踪 S3 | 开 | 高 | GPS 29mA（+OLED 按需） |
| **操作/亮屏（3.3V_SW 必须开）** | 开 | 低 | GPS standby 20µA + 上拉漏电 33~66µA |
| **待机 S2 / 超级深睡（屏灭）** | **关** | 低 | AON 域 ~12µA（GPS 落备份域 8µA，热启动不丢） |

### 0.2 修正的三处错误（v2.0 初稿 / 早期复核中的错误结论）

| # | 错误说法 | 正确事实 |
| --- | --- | --- |
| 1 | 「L76K 没有 ON/OFF 或 STANDBY 脚，只能切 VCC」 | **L76K pin5 就是待机控制脚**，数据手册名为 `WAKEUP`，部分资料标 `STANDBY`。内部上拉，**拉低 = Standby 20µA**，拉高/悬空 = 连续 29mA。v1 的 `GPSEN`(P0.24) 正是这么用的 |
| 2 | 「不需要 GPS EN，P0.13 一根总闸就够」 | **需要**，但用途收窄：留给「3.3V_SW 必须开着（亮屏/写 Flash）却要单独关 GPS」的场合。屏灭待机时**直接关 P0.13 更省电**（12µA vs 53~86µA，见 §5-8） |
| 3 | 「待机时要写 flash，所以不能让 flash 断电」 | 待机无定位 → 无轨迹可写；FindMy 滚动密钥在 RAM 里推导，主密钥开机读一次。但**结论仍按 §0.1 把 flash 挪到 AON**，理由见 §8.2（防擦写中被断电写坏、SPI 无跨域倒灌） |

## 1. 整机电源架构

```
BAT1 1500mAh 软包（自带保护板）
 ├─ B+ ───────────────┬─ VBAT ─→ M1.B+ (主控/充电输入)
 │                    ├─ VBAT ─→ U1.RT9080.VIN
 │                    ├─ VBAT ─→ Q1.S (电量采样高边)
 │                    └─ VBAT ─→ R4 100k → Q1.G
 └─ B− ────────────────────────→ GND

U1 RT9080-33GJ5 (常开, Iq 2µA) ── 3.3V_AON (~12µA)
 ├─ U2 LIS2DW12  VDD/VDD_IO            1µA
 ├─ U4 L76K.V_BCKP (经 R1 100Ω)        8µA
 └─ U3 W25Q128   VCC                  1µA (深度休眠 0xB9)

M1 ProMicro.VCC/3V3 (P0.13 门控) ── 3.3V_SW
 ├─ U4 L76K.VCC      ← 29mA / standby 20µA（由 GPS_EN 控）
 ├─ J2 OLED.VCC      ← 10~20mA
 └─ R14 10k 泄放 → GND（保证断电 <100mV，满足 L76K 要求）

GPS_EN (M1.P1.13) ──→ U4.pin5 WAKEUP   低=Standby 20µA，高=连续 29mA
```

## 5. 固件必须遵守的约束（写进代码注释）

1. **GPS_EN 极性**：低 = standby（20µA），高 = 连续定位。MCU 复位期间引脚高阻 → 模块内部上拉 → 默认连续（安全）。
2. **关 GPS 前**：先把 `GPS_TX` 设为高阻/下拉（否则 3.3V 空闲高电平经 R13 → 模块 RXD 反灌，虽已有 1k 限流，仍应避免）。
3. **每次 GPS 上电后重发 `$PCAS01/02/03/04`**：模块断电/待机会回默认 9600 baud、1Hz；不重配则 115200/5Hz 失效。
4. **W25Q128**：用完发 `0xB9` 进深度休眠（1µA）；下次访问前等 `tRES1`≈3µs。**永不发 0x38（QPI）**。
5. **超级深睡前**：确认没有正在进行的 flash 擦写（NOR 擦写几十~几百 ms），再拉低 P0.13。
6. **LIS2DW12 I²C 地址 = 0x19**（SA0 接 3.3V_AON）。
7. **P0.13 拉低 = 3.3V_SW 断电**（nologo 官方文档明确）。
8. **WAKEUP 内部上拉的隐藏漏电**：L76K pin5 内部有上拉，3.3V_SW 供电时用 P1.13 持续拉低，上拉电阻上就有 3.3V 压差 → 额外漏电（若内部 100kΩ ≈ **33µA**，50kΩ ≈ **66µA**）。这会叠加在手册的 standby 20µA 之上。
   - **策略建议**：待机（屏灭）时**直接拉低 P0.13 关掉 3.3V_SW** 更划算 ——
     `3.3V_SW 开 + GPS standby` ≈ 20µA + 上拉 33~66µA = **53~86µA**；
     `3.3V_SW 关` → GPS 落在备份域 **8µA**（V_BCKP 在 AON，热启动不丢），整机 AON 域 ≈ **12µA**。
     只有「要亮屏或需要 Flash 在 3.3V_SW 上」时才保持 3.3V_SW。
   - **进超级深睡前**把 P1.13 设为 **高阻或低电平**，不要驱动高（否则 3.3V 经模块 ESD 二极管倒灌）。
9. **装好后实测 S2 待机电流**：若比预期高几十 µA，优先怀疑上面这条内部上拉。

## 6. PCB 设计与叠层

### 6.1 叠层：用 4 层板（强烈建议）

采用嘉立创 **JLC04161H-7628**（1.6mm，免费层压结构）：

```
L1  Top      信号 + 器件
L2  GND      完整地平面（不破，关键）
L3  PWR      电源 + 少量走线
L4  Bottom   信号 + 辅助 GND
```

三个理由：

1. **50Ω 微带线宽度合适**：2 层板（1.6mm，参考地间距大）要做到 50Ω，线宽约 **2.8mm**，比 L76K 的 RF_IN 焊盘（pitch 1.1mm）宽出一大截，只能靠共面波导勉强凑；4 层板 Top 到 L2 约 **0.2mm**，50Ω 线宽约 **0.35mm**，正好和 RF_IN 焊盘、0603 π 匹配焊盘平齐，阻抗连续。
2. **L2 整片 GND**：既是后面 §6.2 陶瓷天线的参考地，又能把 SPI/UART/I2C 的数字噪声和射频隔开。
3. **成本几乎无差别**：10×10cm 内 4 层板同样可领免费券，自费也就贵一点。

### 6.2 GPS 陶瓷贴片天线：必须完整铺地，严禁挖空 ⚠

陶瓷块天线（25×25×4 / 18×18mm）是**微带贴片天线**，靠底部完整地平面做反射面形成谐振。**下方挖空会让谐振频率严重偏移，搜星极慢甚至完全搜不到。**

| 项 | 要求 |
| --- | --- |
| 天线正下方 | **顶层与底层都完整铺 GND**，面积 ≥ 陶瓷块尺寸，四周各多留 3~5mm 更好 |
| GND 缝合 | 天线区域周边多打 GND 过孔，把 L1/L2/L4 连成整片 |
| 唯一禁布区 | **馈电探针焊盘周围留 1.5~2mm 环形禁布区**，防止探针短路到地 |
| 摆放 | 陶瓷块朝上；旁边不要紧贴高大金属件或电池，避免遮挡低仰角卫星 |
| 配合 | 馈电点与 RF_IN 之间留 π 匹配焊盘（串联 0Ω + 两个 NM）+ 可选 TVS |

### 6.3 主控模块的板载天线：这里才要挖空

M1（ProMicro）尾部自带 PCB 天线，**这部分与陶瓷天线相反**：天线投影区下方所有铜层挖空（含 L2/L3/L4），区域下方不放器件、不走线。

> **两者不要搞混**：M1 板载天线 = 挖空；U4 陶瓷贴片天线 = 铺满地。

### 6.4 其余布线要求

1. **U4 RF 走线**：50Ω（4 层板上约 0.35mm），尽量短直，不跨分割地。
2. **U2 LIS2DW12**：C5/C10 紧贴 pin9；模组周围留 ≥3mm，避免应力压到 LGA。
3. **U4 L76K**：模组与其他元件 ≥3mm；RF_IN 焊接防静电。
4. **U3**：SOIC-8 **208mil**，勿混 150mil。
5. **U1**：C1/C2 紧贴 VIN/VOUT。
6. **3.3V_SW**：GPS 与 OLED 分两路走，避免 OLED 上电浪涌影响 GPS。
7. **压差要按电源域分开算**（原稿把两条轨写混了）：
   - **3.3V_AON（U1 RT9080）**：负载只有加速度计 ~1µA + Flash ~1µA（待机）/ ~25mA（擦写峰值）+ GPS 备份 8µA。**25mA 时 RT9080 压差仅约 20mV**，电池掉到 **~3.35V 以下** 3.3V_AON 才开始跌落。600mA 的 0.31V 压差在本设计根本用不到。
   - **3.3V_SW（GPS 主电源）**：来自 **ProMicro 板载 LDO**（AP2112 类，600mA，dropout≈250mV@600mA / 轻载远小于此），**与 U1 无关**。电池接近 3.3V+dropout 时 3.3V_SW 开始跌落，但 L76K 最低 2.7V，仍可工作。
   - 所以「低电量优先关 GPS」的理由是**省 29mA 电流**，不是压差不够。

## 7. 可选 / DNP

| 位号 | 状态 | 触发条件 |
| --- | --- | --- |
| R8 / R9 | **DNP 默认** | 库存 OLED 模块已自带 I²C 上拉才不焊；裸屏需焊 |
| C11 / C12（33pF C0G） | 需购 2 颗 | 手册推荐的射频段旁路，与有源/无源天线无关 |
| 天线 TVS | 可选 | 天线外露、易受 ESD 时加 |
| RST / RESET_N 测试点 | 建议留焊盘 | 调试期方便 |

## 8. 数据手册复核依据（关键条目）

1. **LIS2DW12**：SDO/SA0 内部上拉**不可关闭**，ST 明确「低功耗应用请勿接 GND」；退耦要求 **100nF + 10µF 紧贴 pin9**；`RES(pin7) 必须接地`；INT1/INT2 推挽输出不可加上拉；封装 LGA-12 2×2×0.7 pitch 0.5。
2. **W25Q128JV**：`<1µA Power-down (typ.)`、待机 10µA；`/CS` 上电期必须跟随 VCC（建议加上拉）；`/WP` 低 → 状态寄存器不可写、BP 位清不掉（表现为"读正常、擦写全失败"）；`/HOLD` 低 → 总线假死；料号 `S`=SOIC-8 **208mil**、`Q` 后缀 QE 固定=1。
3. **RT9080**：`EN 不可悬空，可直连 VIN`（本设计即如此）；输入/输出各 ≥1µF；封装为 **TSOT-23-5**；pin4 在非 N 版为 NC。
4. **L76K**：18 脚 LCC 10.1×9.7×2.0 pitch 1.10；`VCC` 2.7–3.4V、连续 29mA、standby 20µA、backup 8µA；`WAKEUP` 低有效进 standby；`V_BCKP` 不得晚于 VCC 上电（AON 先于 SW，天然满足）；`V_BCKP` 官方推荐 4.7µF+100nF+33pF；**无源天线直连，不需隔直电容**；`RESERVED` 必须悬空；`SET` 是星座选择不是 FORCE_ON。
5. **ProMicro（nologo）**：P0.13 低 → 关断 3.3V/VCC 输出；BOOST 短接 → 充电 100→300mA；板载 LDO；待机 ~20µA；电池接口 B+/B−。
