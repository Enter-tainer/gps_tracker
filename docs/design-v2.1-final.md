## 1. 电源架构

```
BAT1 1500mAh 软包（带保护板）
 ├─ B+ ──┬─ VBAT ─→ M1.B+ / M1.RAW（主控 + 充电输入）
 │       ├─ VBAT ─→ U1.RT9080N.VIN / EN
 │       └─ VBAT ─→ R5 1MΩ → BAT_ADC → R6 1MΩ → GND（常接低功耗分压 + C9 100nF）
 └─ B− ───────────→ GND

U1 RT9080N-33GJ5（常开，Iq 2µA typ / 4µA max）── 3.3V_AON
 ├─ U2A / U2B 加速度计（VDD + VDD_IO + CS + SA0，二选一，首板装 U2B）
 ├─ U4 L76K.V_BCKP（经 R1 100Ω）
 ├─ U3 W25Q128 VCC（深度休眠 1µA typ）
 └─ 上拉 R2/R3（ACC I²C）、R10/R11/R12（Flash）

M1.5 = 模块板载 LDO 输出（P0.13 门控）── 3.3V_SW
 ├─ U4 L76K.VCC
 ├─ J2 OLED.VCC
 └─ R8/R9（OLED I²C 上拉）

GPS_EN (M1.P1.13) ──→ U4.pin5 WAKEUP
GPS_RST (M1.P0.02) ──→ U4.pin9 RESET_N
```

### 1.1 三种供电状态

| 场景 | 3.3V_SW (P0.13) | GPS_EN | 说明 |
| --- | --- | --- | --- |
| 深睡 / 屏灭待机 | **关** | 低或高阻 | GPS 落备份域（V_BCKP 8µA），热启动不丢星历 |
| 操作 / 亮屏 | 开 | 低（standby 20µA） | OLED 工作，GPS 待命 |
| 追踪记录 | 开 | 高（连续 29mA） | GPS 连续定位，Flash 记录 |

> 屏灭待机**直接关 P0.13**，不要用「3.3V_SW 开着 + GPS standby」——后者要付 WAKEUP 上拉（50~600µA）+ 模块 LDO Iq。

> **电芯账本**还要再加：保护板 3µA + 自放电等效 21~42µA（在 J1 之内、电流表之外）。
> 对外标称写「**AON 支路 13.6µA + 模块实测 ~50µA + 电量分压 1.85µA ≈ 整机 65.5µA**」。模块那 50µA **原因未定位**，归因完成前按此保守估算。

> **睡眠形态（已定：System ON + WFI + RTC）：**
>
> **关键事实：模块的 3.3V LDO 只喂载板的 GPS/OLED，nRF 自己始终由 VDDH 供电。** 所以「P0.13 低（关外设）+ nRF 继续跑 BLE 广播」可以同时做到。
>
> **未知项：模块在「P0.13 拉低、3V3=0V、引脚全高阻、停时钟、WFI」下实测仍有 ~50µA**，手册只能解释约 5µA。**这根因尚未定位**——可能是模块板级某个器件在漏、也可能与测量条件有关（调试器、充电 IC、DC-DC 静态等），需逐项排查后才能定论。
>
> **待排查方向（假设，未验证）**：① 测量时 SWD 是否真拔掉；② 充电 IC 无 VBUS 时的静态；③ 片内 REG0 buck 静态（HV 模式）；④ 模块板上各上拉/分压；⑤ 个例或批次。
>
> 在归因完成前，整机深睡按 **≈65.5µA 保守估算**（AON 13.6 + 模块 50 + 分压 1.85）。
>
> 产品主固件采用 **System ON + WFI + RTC** 形态（非 System OFF）；`bench/power-off` 末尾的 `wfi()` 死循环测的正是这一静态，如需单独测真 System OFF（如运输/仓储模式）需换成 `POWER.systemoff()` 并拔 SWD。

| --- | --- | --- |
| AON 支路 | 13.6µA | 34.8µA |
| 模块板载 LDO（ME6217）Iq | 100µA | 待实测（另有 1µA 说法，差 100 倍） |
| GPS standby | 20µA | 20µA |

**S_gps（连续定位）≈ 35mA**：GPS 29 + MCU 活跃 2~6 + Flash 写峰值 25mA（占空比低）+ OLED 按需。

**首板验收判据**（µA 表）：
- AON 支路 S_deep **13~14µA** 正常；**22µA** ⇒ Flash 停在 ICC1（没进 DPD）；**>300µA** ⇒ 有引脚被驱动低。
- 3.3V_SW 在 P0.13 拉低后 **<100mV** 且保持 ≥100ms。

### 3.3 电量采样（常接低功耗分压）

| 器件/脚 | 网络 |
| --- | --- |
| R5 (1MΩ) | VBAT — BAT_ADC |
| R6 (1MΩ) | BAT_ADC — GND |
| C9 (100nF) | BAT_ADC — GND |

放弃高边双 MOS 开关，改用 `1MΩ / 1MΩ + 100nF` 常接分压：静态电流 **1.85µA@3.7V / 2.1µA@4.2V**（优于双 MOS 高温 `I_DSS` 上限且无温漂），省去 4 颗器件与 1 根 GPIO。戴维南等效源阻 `R5‖R6 = 500kΩ` 满足 nRF52840 SAADC 手册要求（≤800kΩ）；且 `C9 = 100nF` 为 SAADC 内部采样电容（~2.5pF）的 40,000 倍，单次采样压降 `<0.1 LSB`，**无需等待建立时间**（RC 回充时间常数 `τ = 50ms`，按 ≥30s 采样间隔远大于回充时间）。

### 3.4 加速度计（U2A / U2B，二选一）

## 5. 固件约束

1. **GPS_EN 极性**：低 = standby（20µA），高/释放 = 连续（**电平型，非边沿**）。3.3V_SW 上电前 P1.13 保持高阻（内部上拉 → 连续，安全），模块稳定后再切输出。
2. **关 3.3V_SW 前必须把 6 根脚高阻化**：`GPS_EN`(P1.13)、`GPS_RST`(P0.02)、`GPS_TX`(P0.06)、`GPS_RX`(P0.08)、`OLED_SCL`(P0.11)、`OLED_SDA`(P1.04)。
   - 高阻化 = `Dir=Input` + `Input=Disconnect` + `Pull=Disabled` 三件事。⚠ `drop(Uarte)`/`drop(Twim)` **不还原引脚方向**（embassy-nrf 0.11 `deconfigure_pin()` 只关输入缓冲）→ 必须显式配置或写 PIN_CNF。
   - `GPS_EN`/`GPS_RST` 是低有效 + 目标内部上拉 → 只在「输出低 ↔ 输入断开」之间切换、**永不输出高**，这两根结构上不可能倒灌；OLED 只走 TWIM（开漏），禁止 bit-bang 与内部上拉。
   - **`GPS_TX` 串联 `R14 = 1kΩ` 作为硬件兜底**：即使遇到复位、panic、UF2 bootloader 或固件 bug 意外输出高电平，也可将向 L76K ESD 二极管的倒灌电流限制在 `<2.7mA` 以内；正常深睡仍应 `deinit` UARTE0 并置高阻以实现零漏电。
3. **GPS 初始化双波特率探测**：standby 唤醒不丢配置（core/IO 仍供电），只有 3.3V_SW 断电后才可能回默认。断电恢复先试 115200，2s 无响应回 9600 重发 `$PCAS04`→`$PCAS03`→`$PCAS01`→`$PCAS02`；standby 唤醒跳过重配。
4. **W25Q128 深度休眠**：
   - 进：/CS 低 → `0xB9` → 第 8 bit 后拉高 /CS → 3µs 内进入；
   - 出：**必须先发 `0xAB`**，/CS 保持 ≥`tRES1` 3µs；只等待不会退出；
   - **进 DPD 前必须等 BUSY=0**：擦写中除读状态外指令全被忽略，`0xB9` 被静默丢弃（不坏数据，但没睡，停在 ICC1 60µA max 而非 DPD 20µA max）；
   - 上电（或非 DPD 下软复位）后默认待机 10µA；**DPD 中 66h/99h 被忽略，复位不能退出 DPD**；DPD 跨 MCU 复位存活 → 驱动初始化第一步无条件发 `0xAB`；
   - **只允许 1-1-1 标准指令**（本硬件 Dual 也不可能：SPIM 的 MOSI/MISO 单向）。禁止 `32h`/`6Bh`/`EBh`/`77h`/`94h`/`3Bh`/`BBh`/`92h`。QE 固定=1 意味着器件侧接受这些指令，而 IO2/IO3 未接 MCU 又被 10k 拉高 → 发 `32h` 会写坏一半数据位，属静默坏数据；
   - **JEDEC ID = `EF 40 18`**（JVSIQ/JQ）；JVSIM/JM 是 `EF 70 18`。
5. **进深睡前**：SPI 引脚置高阻（R10 已保证 /CS 为高）；写完再睡，擦写中途断电会损坏扇区。
6. **加速度计（U2A / U2B 二选一）**：两颗地址都是 `0x19`，用 `WHO_AM_I` 区分（LIS3DH = 0x33，LIS2DW12 = 0x44）。
   - `P1.15`(INT1) 与 `P0.10`(INT2) **禁止开内部上拉**（传感器推挽输出，开 13k 会灌 254µA）；latched 中断睡前必须清 latch，否则 DETECT 常有效 → 唤醒风暴；睡前关掉其它脚的 sense（PORT/DETECT 是整端口 OR）。
   - 若后续装配 LIS2DW12，需禁用 single-data-conversion-on-demand，并确认 `P0.10` 已切为普通 GPIO（`NFCT_PINS_AS_GPIO`）。
   - I²C 上限 400kHz（4.7k 上拉只对 ≤75pF 总线成立）。
7. **GPS 软件复位**：`GPS_RST` 平时高阻输入；无响应时拉低 **≥100ms** 再释放。
8. **P0.13 拉低 = 3.3V_SW 断电**。深睡顺序：停 GPS → 关 OLED → 6 脚高阻 → 拉低 P0.13 → OLED SCL/SDA 拉低泄放 ~200ms 后切回高阻 → 进 System ON + WFI + RTC。
9. **WAKEUP 内部上拉漏电需实测**：手册未给阻值，姊妹型号标称「拉低到地 standby 约 600µA」，亮屏待机可能在 0.1~0.6mA。
10. **待机策略**：屏灭直接关 P0.13；GPS_EN 只在「3.3V_SW 必须开着」时用于单独关 GPS。
11. **电量采样**：常接 `1MΩ / 1MΩ + 100nF` 分压，无需使能脚与等待建立时间；分压系数 **2.0**；SAADC 用 `0.6V` 内参 / `GAIN1_6`（`P0.31` 数字输入缓冲保持断开），采样周期 ≥30s 或唤醒/上传前采即可。
12. **L76K 下电时序（无泄放电阻）**：手册要求 VCC 掉到 <100mV 并保持 ≥100ms 才完成掉电复位。
    - 日常 GPS 开关走 `GPS_EN`（standby），**不断 3.3V_SW**；
    - 断轨只在深睡发生；轨上 11~21µF 靠漏电放完要 **3.5~127s**（断轨 1s 后仍在 2.4~3.2V）；
    - **正确做法**：拉低 `P0.13` 断轨后，仅将 `OLED_SCL/SDA` 驱动为低约 **200ms**（模块 10k 上拉与 R8/R9 并联构成泄放路径，将 `3.3V_SW` 放至 `<100mV`），**泄放完成后在进入深睡前切回高阻（`Dir=Input` + `Input=Disconnect` + `Pull=Disabled`）**；`GPS_EN`/`GPS_RST`/`GPS_TX`/`GPS_RX` 全程保持高阻，避免若 `WAKEUP`/`RESET_N` 内部上拉挂在 `V_BCKP` 域时倒拉 `3.3V_AON` 漏电；
    - 唤醒后先确保 I²C 引脚处于高阻释放态再拉高 `P0.13`，并在 I²C 初始化前做 9 时钟 bus-clear。
13. **外设实例互斥**：本设计需 2×TWIM + 1×SPI。`SPIM0/TWIM0`、`SPIM1/TWIM1` 是同一实例 → W25Q128 只能用 **SPIM2（推荐，8MHz ≈ 1MB/s）** 或 SPIM3（32MHz ≈ 4MB/s，但需 Errata 198 workaround，且 Errata 195 与深睡预算冲突）。**QSPI 物理不可用**（模块未引出 P0.19/21/23）。v1 的 `SPI3` 不能照搬。
14. **睡前把相关引脚设成高阻**（`Dir=Input` + `Input=Disconnect` + `Pull=Disabled`）：
    - ⚠ **例外：`P0.13` 必须是「输出低」，绝不能高阻、绝不能对它置 default**——模块的 EN 上有上拉到 VDDH（文档估算 10MΩ，`bench/power-off` 注释板级约 ~680kΩ / 漏 ~4.9µA），放高阻 = LDO 被打开 = **多 100~135µA**（单项代价超过其它所有优化之和）
    - `P1.06`(SPI_CS) 输出低 → 330µA；内部下拉 → 143µA
    - `P1.00/P0.24`(ACC I²C) 输出低 → 702µA/根；内部下拉 → 186µA/根
    - `P1.15` 例外：输入 + 无上下拉 + `SENSE=High`
    - 睡前做一次 I²C bus-clear（9 SCL + STOP），防从机拉死 SDA
15. **加速度计档位**：深睡用 **LP ODR=1Hz（2µA）**，需要更快响应用 10Hz（3µA）。**禁止 HR 50Hz（11µA）**；LIS3DH 没有 1µA 档。
16. **LFCLK 用外部晶振**：模块板上有 32.768kHz 晶振（Y2），当前固件用内部 RC（500ppm）→ 改 XTAL 后 MPSL 精度可降到 ~40–50ppm，广播窗口缩短。
17. **BLE 广播间隔**：100ms ≈ 60µA、500ms ≈ 15µA、1s ≈ 9µA、2s ≈ 6µA。建议 ≥1s。
18. **深睡入口清单（System ON + WFI + RTC）**：停 UARTE0/TWIM/SPIM/SAADC/非必需 TIMER，关 USBD 与 VBUS 检测，等 EasyDMA 完成；唤醒源只用 **GPIOTE PORT/DETECT**（绝不用 IN event：17.37µA vs 2.36µA），只给 `P1.15` 和 `P1.11` 开 sense；如在裸板实测纯硬件底噪，须断开调试器。
19. **System OFF 注意事项（仅若未来引入仓储/运输关机模式）**：产品日常睡眠使用 System ON + WFI + RTC，不使用 System OFF；若以后确需进 System OFF，**必须配有效唤醒源**（本板有 `ACC_INT1(P1.15)`、`USER_BTN(P1.11)` 与 `SW3` 复位键），不得上电无条件进 System OFF（Adafruit UF2 双击复位仍可救回 DFU）。

20. **唤醒后的引脚态**：CPU 唤醒 = 复位，但 `PIN_CNF` 是 retained register（需实测确认）。**无论哪种结果，启动最早期必须显式建立全部引脚安全态，不得依赖复位默认值。**

### 6.4 其余布线

1. **U4 RF 走线**：50Ω（0.35mm），尽量短直，不跨分割地；L2 在走线正下方连续，两侧加地过孔。
2. **U2A/U2B**：C5/C10 紧贴 U2A pin9（装 U2B 时兼顾 pin14）；器件下方不走线不打孔；远离板边；所贴器件所有焊盘必焊。
3. **U4**：RF_IN 焊接防静电；相邻 GND 脚不做热焊盘、满连接。
4. **U3**：C6/C13 紧贴 VCC，GND 回流到 pin4（与 pin8 对角）。
5. **U1**：C1/C2 紧贴 VIN/VOUT，地端就近打过孔；SNS 走线接负载端。
6. **3.3V_SW**：GPS 与 OLED 分两路走，GPS 支路先经 C7 再进 U4.VCC。
7. **电源线宽**：VBAT（充电 300mA）0.5~1.0mm，3.3V_SW 0.5mm，每段 ≥2 个 0.3mm 过孔；L3 平面按 3.3V_AON / 3.3V_SW / VBAT 三区分割，分割缝不跨 RF/时钟/SPI 走线。
8. **压差**：3.3V_AON 由 U1 供（25mA 时压差约 15mV，电池 ~3.32V 以下开始跌）；3.3V_SW 由模块 LDO 供（VBAT 2.8V 时轨约 2.74~2.77V，逼近 L76K 的 2.7V 下限）。
9. **测试点**：3.3V_AON、3.3V_SW、VBAT、GPS_RST、ACC_INT1、GND 各留焊盘。

### 6.5 ESD

不做额外加固（沿用 v1：GPS 侧未加 TVS 且长期正常）：天线在壳内、走线全在板内，主要 ESD 入口 USB 在模块上且自带保护。

## 8. 手册依据（关键条目）

1. **LIS2DW12**：SDO/SA0 内部上拉不可关闭（手册未给阻值，3.3V 约 22kΩ），接 GND 持续漏 ~140µA，掉电电流仅 50nA → 接 3.3V_AON；退耦 100nF + 10µF 紧贴 pin9；`RES(pin7) 必须接 GND`；INT1/INT2 默认推挽、不可加上拉。
2. **LIS3DHTR**：SA0 接 3.3V_AON = 0x19（内部上拉不可关，接 GND 估计漏 ~150µA）；VDD 与 VDD_IO 均接 3.3V_AON；`RES(pin10) 必须接 GND`；INT1/INT2 默认推挽、不可加上拉。
3. **W25Q128JV**：DPD 1µA typ / 20µA max、待机 10µA typ / 60µA max；/CS 上电期须跟随 VCC；DPD 退出必须先发 `0xAB`；`Q` 后缀 QE 固定=1 → pin3/pin7 为 IO2/IO3；JV 无 QPI 指令；`S` = SOIC-8 208mil。
4. **RT9080 / RT9080N**：EN 不可悬空、可直连 VIN；输出电容「有效 ≥1µF」无上限；Iq 2µA typ / 4µA max；dropout 0.31V@600mA。**pin4**：非 N 版为 NC，N 版为 SNS（必须接 VOUT，内部链路 550nA，SNS 电位 = 该料号标称 VOUT）。
5. **L76K**：VCC 2.7–3.4V、连续 29mA、standby 20µA、backup 8µA；WAKEUP 低有效进 standby；RESET_N 内部上拉、禁止外加上拉；**V_BCKP 不得晚于 VCC 上电**；推荐 V_BCKP 4.7µF + 100nF + 33pF；无源天线直连不需隔直电容；RESERVED 必须悬空；SET 是星座选择。
6. **模块板载 LDO（丝印 `S2TK`）**：`S2` 是 **ME6211C33M5G** 的丝印前缀（`S2` + 两位批号，如 S2WI/S2TK），**不是**参考图上标的 ME6217。两者 SOT23-5 引脚相同（1=VIN 2=GND 3=EN 4=NC 5=VOUT）；Iq 分别是 ≈30~55µA（ME6211）与 100µA typ / 130µA max（ME6217）。**已实测确认：P0.13 拉低后 3V3 焊盘为 0V，LDO 确实关断** → 50µA 不是 LDO 的，来源见 §9.3。
7. **ME6217 / TP4054 / BAT60B**：ME6217 Iq **100µA typ / 130µA max**（关断 0.1/1.0µA，CE 禁止悬空），**无主动输出放电**（仅内部几百 kΩ 被动泄放）；TP4054 无 VBUS 时 BAT 睡眠电流 **3µA typ / 5µA max**；BAT60B 反漏在 VBUS 浮空时被自限到 nA~亚µA，**但给 VBUS 加下拉会变成 5~15µA（高温数百 µA）**。
8. **ProMicro（nologo）**：P0.13 低 → 关断 3.3V/VCC；BOOST 短接 → 充电 100→300mA（电池须 >500mAh）；待机 ~20µA；电池接口 B+/B−。

### 9.4 低电量策略

3.3V_AON 在电池 < ~3.32V 时随电池跌落，而 **W25Q128 最低工作电压 2.7V**：

- 电池 < **2.85V**：禁止开 GPS/OLED 高负载（3.3V_SW 已逼近 L76K 的 2.7V 下限）
- 电池 < **2.75V**：软件禁止 Flash 擦写并停止记录，避免半写损坏扇区（`W25Q128JVSIQ` 因 `QE=1` 禁用 `/WP` 引脚，故不在欠压临界点写非易失状态寄存器 `SRP/SRL`）
