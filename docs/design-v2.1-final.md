## 1. 电源架构

```
BAT1 1500mAh 软包（带保护板）
 ├─ B+ ──────────────┬─ VBAT ─→ M1.B+ / M1.RAW（主控 + 充电输入）
 │                   ├─ VBAT ─→ U1.RT9080N.VIN / EN
 │                   ├─ VBAT ─→ Q1.S（电量采样高边）
 │                   └─ VBAT ─→ R4 100k → Q1.G
 └─ B− ────────────────────→ GND

U1 RT9080N-33GJ5（常开, Iq 2µA typ / 4µA max）── 3.3V_AON
 ├─ U2A / U2B 加速度计  VDD + VDD_IO + CS + SA0
 ├─ U4 L76K.V_BCKP（经 R1 100Ω）
 └─ U3 W25Q128 VCC（深度休眠 1µA typ）

M1.VCC/3V3（P0.13 门控）── 3.3V_SW
 ├─ U4 L76K.VCC
 ├─ J2 OLED.VCC
 └─ R14 100k 泄放 → GND

GPS_EN (M1.P1.13) ──→ U4.pin5 WAKEUP
GPS_RST (M1.P0.02) ──→ U4.pin9 RESET_N
```

### 1.1 三种供电状态

| 场景 | 3.3V_SW (P0.13) | GPS_EN | 说明 |
| --- | --- | --- | --- |
| 追踪 S3 | 开 | 高 | GPS 连续定位 29mA（OLED 按需） |
| 操作 / 亮屏 | 开 | 低 | GPS 进 standby 20µA，WAKEUP 上拉另有漏电（实测确认） |
| 待机 S2 / 深睡 | **关** | 低 | GPS 落备份域 8µA（V_BCKP 在 AON，热启动不丢） |

**深睡功耗**：3.3V_AON 支路 ≈ 12µA typ（加速度计 1µA + Flash DPD 1µA + GPS 备份 8µA + LDO 2µA），
最坏约 31µA；整机还需叠加模块自身静态（nologo 标称待机 ~20µA）。

> 屏灭待机时**直接关 P0.13**，不要用「3.3V_SW 开着 + GPS standby」——后者要付 WAKEUP 上拉漏电 + R14 33µA。

## 3. 逐器件连接

### 3.1 M1 — nRF52840 ProMicro（26 pad）

**符号说明**：本工程原理图用 26 脚排针符号（库件 `26PIN`）代替模块焊盘，**引脚号 1–26 与模块焊盘号一一对应**（见下表）。
模块专用符号需在库中自建后替换，替换时保持焊盘号不变即可；v1 工程内嵌的 `PROMICRO NRF52840 方形焊盘-BBB` 符号可作绘制参考。

**v1 焊盘编号换算**（v1 符号用 1–26 脚）：左列 Lₙ = 27−n（L1=脚26 ⋯ L13=脚14）｜右列 Rₙ = n（R1=脚1 ⋯ R13=脚13）。

| 1 | B+ | VBAT | 电池正 |
| 2 | RAW | VBAT | 与 B+ 同节点（模块充电输入） |
| 3 | GND | GND | |
| 4 | RST | RST | → SW3 → GND（内部上拉，不外加上拉） |
| 5 | 3.3V | 3.3V_SW | VCC/3V3 输出，P0.13 门控 |
| 6 | D21 / P0.31 | BAT_ADC | AIN7 |
| 7 | D20 / P0.29 | BAT_ADC_EN | → Q2.G |
| 8 | D19 / P0.02 | GPS_RST | → U4.RESET_N（平时高阻） |
| 9 | D18 / P1.15 | ACC_INT1 | ← 加速度计 INT1 |
| 10 | D15 / P1.13 | GPS_EN | → U4.WAKEUP（低=Standby） |

### 3.2 U1 — RT9080N-33GJ5（TSOT-23-5）

| 脚 | 网络 | 备注 |
| --- | --- | --- |
| 1 VIN | VBAT | + C1 1µF 到 GND |
| 2 GND | GND | |
| 3 EN | VBAT | 直接短接 VIN（常开，不可悬空） |
| 4 **SNS/NC** | **3.3V_AON** | **一律接 VOUT**：N 版是 SNS（接 VOUT 才是闭环，悬空/接 GND 都会让输出冲到 ≈VIN）；非 N 版是 NC（接 VOUT 无电流，安全）。线短粗，接在 C2 正端 |
| 5 VOUT | 3.3V_AON | + C2 10µF 到 GND |

> **上电验证**（首板必须做，用限流电源）：VIN 加 4.2V / 限流 50mA，VOUT 接 1kΩ 假负载。
> - 通断档测 **pin4 ↔ pin5 应为 <几 Ω**（确认 SNS 真接到 VOUT，排除虚焊）；
> - 上电测 VOUT：**3.23~3.37V** 为正常；**≈VIN（>3.6V）= SNS 没接上，立刻断电**（限流下不会损坏）。
> 判据只看 VOUT 与通断，**不要用万用表直接读 pin4 电压**（该节点内阻约 6MΩ，表笔会引入误差）。

### 3.3 电量采样（Q1 + Q2）

| 器件/脚 | 网络 |
| --- | --- |
| Q1.S (pin2) | VBAT |
| Q1.G (pin1) | Q1_G |
| Q1.D (pin3) | ADC_HI |
| R4 | VBAT — Q1_G |
| Q2.D (pin3) | Q1_G |
| Q2.G (pin1) | BAT_ADC_EN |
| Q2.S (pin2) | GND |
| R7 | BAT_ADC_EN — GND |
| R5 | ADC_HI — BAT_ADC |
| R6 | BAT_ADC — GND |
| C9 | BAT_ADC — GND |

`BAT_ADC_EN` 拉高 → Q2 导通 → Q1 栅极拉低 → Q1 导通 → VBAT 经 R5/R6 分压到 BAT_ADC；拉低后 Q1 关断，分压链无回路（≤1µA 规格上限）。

**建立时间**：戴维南阻抗 R5‖R6 = 100kΩ，C9 100nF → τ = 10ms；12bit 精度需约 **8.5τ ≈ 90ms**。

### 3.4 加速度计（U2A / U2B，二选一）

两套焊盘并排，共享信号，各自定地址；**只装一颗，另一个 DNP**。

| 信号 | U2A：LIS2DW12TR（LGA-12） | U2B：LIS3DHTR（LGA-16） |
| --- | --- | --- |
| SCL | 脚1 ← ACC_SCL | 脚4 ← ACC_SCL |
| SDA | 脚4 ↔ ACC_SDA | 脚6 ↔ ACC_SDA |
| CS（I²C 模式） | 脚2 → 3.3V_AON | 脚8 → 3.3V_AON |
| **SA0（地址）** | 脚3 → **3.3V_AON**（0x19） | 脚7 → **3.3V_AON**（0x19） |
| INT1 | 脚12 → ACC_INT1 | **脚11** → ACC_INT1 |
| INT2 | 脚11 悬空 | 脚9 悬空 |
| VDD | 脚9 → 3.3V_AON | 脚14 → 3.3V_AON |
| VDD_IO | 脚10 → 3.3V_AON | 脚1 → 3.3V_AON |
| GND | 脚6 / **脚7 RES 必须接 GND** / 脚8 | 脚5 / **脚10 RES 必须接 GND** / 脚12 |
| 退耦 | C5 100nF + C10 10µF 紧贴脚9 | 共用 C5 + C10 |

两颗 SA0 均接 3.3V_AON → **地址都是 0x19**。LIS3DH 的 SDO/SA0 内部上拉不可关（3.3V 时约 22kΩ，接 GND 会持续漏 ~150µA），
所以不能像常见做法那样接 GND。二选一时同址无冲突，固件用 **WHO_AM_I** 区分（LIS2DW12 = **0x44**，LIS3DH = **0x33**）。

## 5. 固件约束

1. **GPS_EN 极性**：低 = standby（20µA），高/释放 = 连续（**电平型，非边沿触发**）。3.3V_SW 上电前 P1.13 应为高阻（内部上拉 → 连续定位，安全），模块稳定后再切输出。
2. **关 3.3V_SW 前必须把 5 根脚全部高阻化**：`GPS_EN`(P1.13)、`GPS_RST`(P0.02)、`GPS_TX`(P0.06)、`OLED_SCL`(P0.11)、`OLED_SDA`(P1.04)。模块/OLED 的 IO 域 = VCC，绝对最大 `VCC+0.3V`，而 MCU 仍由电池供电——这些脚若保持输出高电平会经 ESD 二极管倒灌，把 3.3V_SW 抬到 0.6~2.7V，关断失效且 GPS 进欠压异常态。R13 1k 只限流、不构成过压保护。
3. **GPS 初始化用双波特率探测**：standby 唤醒不丢配置（core/IO 仍供电），只有 3.3V_SW 断电后才可能回默认。断电恢复路径先按 115200 试，2s 无响应回 9600 重发 `$PCAS04`→`$PCAS03`→`$PCAS01`→`$PCAS02`；standby 唤醒路径跳过重配。
4. **W25Q128 深度休眠**：
   - 进：/CS 低 → 发 `0xB9` → 第 8 bit 后拉高 /CS → 3µs 内进入；
   - 出：**必须先发 `0xAB`**，/CS 拉高保持 ≥`tRES1` 3µs（带 ID 读用 `tRES2` 1.8µs）；只等待不会退出；
   - 上电/复位后默认待机 10µA，且 **DPD 状态跨 MCU 复位存活** → 驱动初始化第一步无条件发 `0xAB`；
   - 只用 Standard/Dual SPI，**禁止四线指令（`0x6B`/`0xEB`/`0x32`/`0x34`）**。
5. **进 System OFF 前**：SPI 引脚置高阻（R10 已保证 /CS 为高）。flash 在 AON 上，拉低 P0.13 不影响它，但擦写中途断电会损坏扇区，写完再睡。
6. **加速度计**：地址 U2A=0x19 / U2B=0x18，启动探测自适应。LIS2DW12 **禁用 single-data-conversion-on-demand 与 SLP_MODE_SEL=0**（该模式下 INT2 变时钟输入，而 INT2 悬空）；INT1/INT2 默认推挽输出，**不得加上拉**；I²C 上限 **400kHz**（4.7k 上拉只对 400kHz 成立）。
7. **GPS 软件复位**：`GPS_RST`(P0.02) 平时高阻输入；GPS 无响应时拉低 **≥100ms** 再释放。
8. **P0.13 拉低 = 3.3V_SW 断电**。深睡顺序：停 GPS → 关 OLED → P1.13 高阻 → 拉低 P0.13 → System OFF。
9. **WAKEUP 内部上拉漏电需实测**：手册未给阻值，姊妹型号同脚位标称「拉低到地 standby 约 600µA」。叠加 R14 的 33µA 后，亮屏待机可能在 0.1~0.6mA 量级。
10. **待机策略**：屏灭时直接关 P0.13；GPS_EN 只在「3.3V_SW 必须开着」时用于单独关 GPS。
11. **电量采样**：`BAT_ADC_EN` 拉高后**至少等 90ms** 再采，采样后拉低；分压系数 **2.0**（200k/200k）；SAADC 用 0.6V 内参 / GAIN1_6 / 12bit / 40µs。
12. **L76K 下电时序**：VCC 必须掉到 **<100mV 并保持 ≥1s** 才能重新上电（R14 100k 约 3.5s 掉到 100mV，固件保证断电 ≥1s）。

## 6. PCB 设计与机械

### 6.1 叠层（4 层）

嘉立创 **JLC04161H-7628**（1.6mm）：L1 信号+器件 / **L2 完整 GND** / L3 电源+少量走线 / L4 信号+GND。

| 项 | 值 |
| --- | --- |
| 下单要求 | 指定 JLC04161H-7628，**勾选阻抗控制** |
| L1→L2 介质 | 0.21mm（7628×1 prepreg） |
| εr | 4.4~4.6 |
| **50Ω 微带线宽** | **0.35mm**（≈13.75mil） |
| 2 层板对照 | 1.6mm 厚时 50Ω 需约 2.9mm 线宽，远宽于 L76K 的 RF_IN 焊盘（pitch 1.1mm） |

用 4 层的理由：50Ω 线宽可与 RF_IN 焊盘同量级过渡；L2 连续地给 RF 提供参考面；陶瓷贴片需要不被分割的完整地；SOIC-8 208mil + 4mm 陶瓷块需要板刚性。

### 6.2 机械与外形（沿用 v1，外壳不改）

| 项 | 约束 |
| --- | --- |
| 板框 | **95.0 × 30.0 mm，四角 R2** |
| 板厚 | 1.6 mm |
| 接口位置 | OLED 排母、两颗按键、电池座、GPS 陶瓷天线、模块天线朝向 —— **全部沿用 v1**，不得移出原有开孔 |
| 外壳开孔 | ① 模块背面调试接口（SWD）操作孔；② 模块背面 **BOOST 焊盘** 观察/补焊孔 |
| 内部高度 | 陶瓷天线 4mm 高，外壳顶壁上方留 ≥2mm 且不得金属化 |

布局顺序：先按 v1 钉死外形与接口位置，再把新器件（加速度计比原型号小、去掉 SD 卡座与气压计、W25Q128 只占 SOP-8）塞中间空隙。

### 6.3 天线

**两块天线都沿用 v1 的处理方式**（v1 同尺寸板框、同款 25×25×4 陶瓷贴片，实机长期使用正常）。

| 天线 | 做法 |
| --- | --- |
| U4 GPS 陶瓷贴片 | RF_IN **直连**（无 π 匹配网络，同 v1）；天线下方按 v1 铺地；位置与朝向不变 |
| M1 模块板载天线 | 按 v1 的挖空范围与朝向；位置不变 |

### 6.4 其余布线

1. **U4 RF 走线**：50Ω（0.35mm），尽量短直，不跨分割地；L2 在走线正下方连续，两侧加地过孔。
2. **U2A/U2B**：C5/C10 紧贴 U2A pin9；器件下方不走线、不打孔；远离板边与受力点；所有焊盘必焊。
3. **U4**：RF_IN 焊接防静电；相邻 GND 脚不做热焊盘、满连接。
4. **U3**：SOP-8 / SOIC-8 **208mil**；C6/C13 紧贴 VCC。
5. **U1**：C1/C2 紧贴 VIN/VOUT，地端就近打过孔；SNS 走线接负载端。
6. **3.3V_SW**：GPS 与 OLED 分两路走，GPS 支路先经 C7 再进 U4.VCC。
7. **电源线宽**：VBAT（充电 300mA）0.5~1.0mm，3.3V_SW 0.5mm，每段≥2 个 0.3mm 过孔；L3 平面 3.3V_AON / 3.3V_SW / VBAT 三区分割，分割缝不跨 RF/时钟/SPI 走线。
8. **压差**：3.3V_AON 由 U1 供（25mA 时压差约 15mV，电池 ~3.32V 以下开始跌）；3.3V_SW 由模块板载 LDO 供，L76K 最低 2.7V 仍可用。低电量优先关 GPS 是为省 29mA，不是压差不够。
9. **测试点**：3.3V_AON、3.3V_SW、VBAT、GPS_RST、ACC_INT1、GND 各留焊盘。

### 6.5 ESD

不做额外加固（沿用 v1，v1 的 GPS 侧未加 TVS 且长期使用正常）：天线在壳内、走线全在板内，主要 ESD 入口 USB 在模块上且自带保护。

## 8. 手册依据（关键条目）

1. **LIS2DW12**：SDO/SA0 内部上拉**不可关闭**（3.3V 时约 23kΩ），接 GND 会持续漏 ~140µA，而掉电电流仅 50nA → 接 3.3V_AON；退耦 **100nF + 10µF 紧贴 pin9**；`RES(pin7) 必须接 GND`；INT1/INT2 默认推挽输出，不可加上拉；LGA-12 2×2×0.7，pitch 0.5。
2. **LIS3DHTR**：LGA-16 3×3×1.0；SA0 接 GND = 0x18；VDD 与 VDD_IO 均接 3.3V_AON。
3. **W25Q128JV**：DPD **1µA typ / 20µA max**、待机 10µA typ；`/CS` 上电期须跟随 VCC（手册建议加上拉）；**DPD 退出必须先发 `0xAB`**；上电默认待机且 DPD 跨 MCU 复位存活；`Q` 后缀 **QE 固定=1** → pin3/pin7 为 IO2/IO3；JV 系列无 QPI 指令；料号 `S` = SOIC-8 **208mil**。
4. **RT9080 / RT9080N**：`EN 不可悬空，可直连 VIN`；输出电容"有效 ≥1µF"，无最大限制；Iq 2µA typ / 4µA max；TSOT-23-5；dropout 0.31V@600mA。
   **pin4**：非 N 版为 NC（悬空或接 GND 均可），N 版为 SNS（**必须接 VOUT**，内部链路电流 550nA，SNS 电位 = 该料号标称 VOUT，接 VOUT 即分压比 1）。手册 DS9080-08 §15 Figure 1「Application with Sense Function」即无外部分压的固定输出图。**本设计统一接 VOUT，两种变体通用**。
5. **L76K**：18 脚 LCC 10.1×9.7×2.0 pitch 1.10；VCC 2.7–3.4V、连续 29mA、standby 20µA、backup 8µA；`WAKEUP` 低有效进 standby；`RESET_N` 内部上拉到 3.3V、禁止外加上拉；`V_BCKP` 不得晚于 VCC 上电；官方推荐 V_BCKP 4.7µF + 100nF + 33pF；无源天线直连不需隔直电容；`RESERVED` 必须悬空；`SET` 是星座选择。
6. **ProMicro（nologo）**：P0.13 低 → 关断 3.3V/VCC；BOOST 短接 → 充电 100→300mA（电池须 >500mAh）；板载 LDO 输出 3.3V；待机 ~20µA；电池接口 B+/B−。

### 9.4 低电量策略（补充约束）

3.3V_AON 在电池 &lt; ~3.32V 时随电池跌落，而 **W25Q128 最低工作电压 2.7V**：
电池低于 **2.75V** 时应禁止 flash 擦写并停止记录，避免半写损坏扇区。
