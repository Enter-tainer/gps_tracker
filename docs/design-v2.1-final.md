## 1. 电源架构

```
BAT1 1500mAh 软包（带保护板）
 ├─ B+ ──────────────┬─ VBAT ─→ M1.B+ / M1.RAW（主控 + 充电输入）
 │                   ├─ VBAT ─→ U1.RT9080N.VIN / EN
 │                   ├─ VBAT ─→ Q1.S（电量采样高边）
 │                   └─ VBAT ─→ R4 100k → Q1.G
 └─ B− ────────────────────→ GND

U1 RT9080N-33GJ5（常开, Iq 2µA typ / 4µA max）── 3.3V_AON
 ├─ U2A / U2B 加速度计  VDD + VDD_IO + CS + SA0
 ├─ U4 L76K.V_BCKP（经 R1 100Ω）
 └─ U3 W25Q128 VCC（深度休眠 1µA typ）

M1.VCC/3V3（P0.13 门控）── 3.3V_SW
 ├─ U4 L76K.VCC
 └─ J2 OLED.VCC

GPS_EN (M1.P1.13) ──→ U4.pin5 WAKEUP
GPS_RST (M1.P0.02) ──→ U4.pin9 RESET_N
```

### 1.1 三种供电状态

| 场景 | 3.3V_SW (P0.13) | GPS_EN | 说明 |
| --- | --- | --- | --- |
| 追踪 S3 | 开 | 高 | GPS 连续定位 29mA（OLED 按需） |
| 操作 / 亮屏 | 开 | 低 | GPS 进 standby 20µA，WAKEUP 上拉另有漏电（实测确认） |
| 待机 S2 / 深睡 | **关** | 低 | GPS 落备份域 8µA（V_BCKP 在 AON，热启动不丢） |

**深睡功耗**：3.3V_AON 支路 ≈ 12µA typ（加速度计 1µA + Flash DPD 1µA + GPS 备份 8µA + LDO 2µA），
最坏约 31µA（含采样链关断漏电 I_DSS 上限 2µA@25℃ / 10µA@55℃）；
整机还需叠加**模块自身静态**（nologo 标称待机 ~20µA，实测好批 4µA / 坏批可达 60µA）
+ **模块内部常接的电池分压**（§3.1 注释，P0.04 内部，不可断，待实测）。

> 屏灭待机时**直接关 P0.13**，不要用「3.3V_SW 开着 + GPS standby」——后者要付 WAKEUP 上拉漏电（数十~数百 µA）。

## 3. 逐器件连接

### 3.1 M1 — nRF52840 ProMicro（26 pad）

**符号说明**：本工程原理图用 26 脚排针符号（库件 `26PIN`）代替模块焊盘，**引脚号 1–26 与模块焊盘号一一对应**（见下表）。
模块专用符号需在库中自建后替换，替换时保持焊盘号不变即可；v1 工程内嵌的 `PROMICRO NRF52840 方形焊盘-BBB` 符号可作绘制参考。

**符号备注**：当前原理图用的 `26PIN` 库符号实际有 **28 个引脚**——除 1–26 外，(540,750)/(540,460) 还有两个**固定脚，模块上无对应焊盘**。换成 v1 的 26 pad 封装时必须删掉这两个脚，否则 PCB 会带入两个多余焊盘。

**v1 焊盘编号换算**（v1 符号用 1–26 脚）：左列 Lₙ = 27−n（L1=脚26 ⋯ L13=脚14）｜右列 Rₙ = n（R1=脚1 ⋯ R13=脚13）。

| 2 | RAW | VBAT | 与 B+ 同节点（模块充电输入） |
| 3 | GND | GND | |
| 4 | RST | RST | → SW3 → GND（内部上拉，不外加上拉） |
| 5 | 3.3V | 3.3V_SW | VCC/3V3 输出，P0.13 门控 |

### 3.2 U1 — RT9080N-33GJ5（TSOT-23-5）

| 脚 | 网络 | 备注 |
| --- | --- | --- |
| 1 VIN | VBAT | + C1 **2.2µF** 到 GND |
| 2 GND | GND | |
| 3 EN | VBAT | 直接短接 VIN（常开，不可悬空） |
| 4 **SNS/NC** | **3.3V_AON** | **一律接 VOUT**：N 版是 SNS（接 VOUT 才是闭环，悬空/接 GND 都会让输出冲到 ≈VIN）；非 N 版是 NC（接 VOUT 无电流，安全）。线短粗，接在 C2 正端 |
| 5 VOUT | 3.3V_AON | + C2 10µF 到 GND |

> **上电验证**（首板必须做，用限流电源）：VIN 加 4.2V / 限流 50mA，VOUT 接 1kΩ 假负载。
> - 通断档测 **pin4 ↔ pin5 应为 <几 Ω**（确认 SNS 真接到 VOUT，排除虚焊）；
> - 上电测 VOUT：**3.23~3.37V** 为正常；**≈VIN（>3.6V）= SNS 没接上，立刻断电**（限流下不会损坏）。
> 判据只看 VOUT 与通断，**不要用万用表直接读 pin4 电压**（该节点内阻约 6MΩ，表笔会引入误差）。

### 3.3 电量采样（Q1 + Q2）

| 器件/脚 | 网络 |
| --- | --- |
| Q1.S (pin2) | VBAT |
| Q1.G (pin1) | Q1_G |
| Q1.D (pin3) | ADC_HI |
| R4 | VBAT — Q1_G |
| Q2.D (pin3) | Q1_G |
| Q2.G (pin1) | BAT_ADC_EN |
| Q2.S (pin2) | GND |
| R7 | BAT_ADC_EN — GND |
| R5 | ADC_HI — BAT_ADC |
| R6 | BAT_ADC — GND |
| C9 | BAT_ADC — GND |

`BAT_ADC_EN` 拉高 → Q2 导通 → Q1 栅极拉低 → Q1 导通 → VBAT 经 R5/R6 分压到 BAT_ADC；拉低后 Q1 关断，分压链无回路（Q1+Q2 的 I_DSS 典型 <0.1µA；**手册规格上限 2µA@25℃ / 10µA@55℃**，条件 VDS=30V，实际 4.2V 下更低）。

**建立时间**：戴维南阻抗 R5‖R6 = 100kΩ，C9 100nF → τ = 10ms；12bit 精度需约 **8.5τ ≈ 90ms**。

### 3.4 加速度计（U2A / U2B，二选一）

两套焊盘并排，共享信号，**两颗 SA0 都接 3.3V_AON（同址 0x19）**；**只装一颗，另一个 DNP**。
> **首板默认装 U2B（LIS3DHTR）**：它是库存件，且固件（`lis3dh` crate）只支持它。U2A（LIS2DW12）需先补驱动才能用。

| 信号 | U2A：LIS2DW12TR（LGA-12） | U2B：LIS3DHTR（LGA-16） |
| --- | --- | --- |
| SCL | 脚1 ← ACC_SCL | 脚4 ← ACC_SCL |
| SDA | 脚4 ↔ ACC_SDA | 脚6 ↔ ACC_SDA |
| CS（I²C 模式） | 脚2 → 3.3V_AON | 脚8 → 3.3V_AON |
| **SA0（地址）** | 脚3 → **3.3V_AON**（0x19） | 脚7 → **3.3V_AON**（0x19） |
| INT1 | 脚12 → ACC_INT1 | **脚11** → ACC_INT1 |
| INT2 | 脚11 悬空 | 脚9 悬空 |
| VDD | 脚9 → 3.3V_AON | 脚14 → 3.3V_AON |
| VDD_IO | 脚10 → 3.3V_AON | 脚1 → 3.3V_AON |
| GND | 脚6 / **脚7 RES 必须接 GND** / 脚8 | 脚5 / **脚10 RES 必须接 GND** / 脚12 |
| 退耦 | C5 100nF + C10 10µF 紧贴脚9 | 共用 C5 + C10 |

两颗 SA0 均接 3.3V_AON → **地址都是 0x19**。LIS3DH 的 SDO/SA0 内部上拉不可关（手册只写"无通信时由内部上拉驱动"，**未给阻值**；按 LIS2DW12 同类结构估算 3.3V 时约 20kΩ，接 GND 会持续漏 ~150µA），
所以不能像常见做法那样接 GND。二选一时同址无冲突，固件用 **WHO_AM_I** 区分（LIS2DW12 = **0x44**，LIS3DH = **0x33**）。

> ⚠ **两颗都装会彻底不可用**（比"INT1 打架"更致命）：同址 0x19 会导致**双 ACK + SDA 线与**，
> 主机读回的 WHO_AM_I 是 `0x33 & 0x44 = 0x00`，探测逻辑会把两颗都判成"无器件"；
> 写入也会同时进两颗。**装配必须二选一。**

## 5. 固件约束

1. **GPS_EN 极性**：低 = standby（20µA），高/释放 = 连续（**电平型，非边沿触发**）。3.3V_SW 上电前 P1.13 应为高阻（内部上拉 → 连续定位，安全），模块稳定后再切输出。
2. **关 3.3V_SW 前必须把 5 根脚全部高阻化**：`GPS_EN`(P1.13)、`GPS_RST`(P0.02)、`GPS_TX`(P0.06)、`OLED_SCL`(P0.11)、`OLED_SDA`(P1.04)。模块/OLED 的 IO 域 = VCC，绝对最大 `VCC+0.3V`，而 MCU 仍由电池供电——这些脚若保持输出高电平会经 ESD 二极管倒灌，把 3.3V_SW 抬到 0.6~2.7V，关断失效且 GPS 进欠压异常态。R13 1k 只限流、不构成过压保护。
3. **GPS 初始化用双波特率探测**：standby 唤醒不丢配置（core/IO 仍供电），只有 3.3V_SW 断电后才可能回默认。断电恢复路径先按 115200 试，2s 无响应回 9600 重发 `$PCAS04`→`$PCAS03`→`$PCAS01`→`$PCAS02`；standby 唤醒路径跳过重配。
4. **W25Q128 深度休眠**：
   - 进：/CS 低 → 发 `0xB9` → 第 8 bit 后拉高 /CS → 3µs 内进入；
   - 出：**必须先发 `0xAB`**，/CS 拉高保持 ≥`tRES1` 3µs（带 ID 读用 `tRES2` 1.8µs）；只等待不会退出；
   - **进 DPD 前必须等 BUSY=0**：擦写进行中除 Read Status 外的指令全被忽略，`0xB9` 会被**静默丢弃**（不坏数据，但根本没睡，停在 ICC1 60µA max 而非 DPD 20µA max）；
   - 上电（或非 DPD 状态下的软复位）后默认待机 10µA；**DPD 中 66h/99h 被忽略，即复位不能退出 DPD**；**DPD 状态跨 MCU 复位存活**（VCC 在 AON 上不掉）→ 驱动初始化第一步无条件发 `0xAB`；
   - **只允许 1-1-1 标准指令**。本硬件 **Dual 也不可能**（nRF SPIM 的 MOSI/MISO 是单向的，`3Bh/BBh/92h` 需要中途换向）。
     **禁止**：`32h`(Quad Page Program)、`6Bh`/`EBh`(Quad Read)、`77h`(Set Burst with Wrap)、`94h`(Mftr/Device ID Quad)、`3Bh`/`BBh`/`92h`(Dual)。
     注意 **QE 固定=1 意味着器件侧接受这些指令**（不是"被拒绝"），而 IO2/IO3 未接 MCU 且被 10k 拉高 → 发 `32h` 会把一半数据位写成 1、发 `6Bh/EBh` 读出伪数据，属**静默坏数据**。
   - **JEDEC ID = `EF 40 18`**（`JVSIQ`/JQ）；`JVSIM/JM` 是 `EF 70 18`——驱动别按"JV=70 18"硬校验。
5. **进 System OFF 前**：SPI 引脚置高阻（R10 已保证 /CS 为高）。flash 在 AON 上，拉低 P0.13 不影响它，但擦写中途断电会损坏扇区，写完再睡。
6. **加速度计**：两颗地址**都是 0x19**，用 WHO_AM_I（LIS2DW12=0x44 / LIS3DH=0x33）区分（⚠ `0x33` 同时也是 SA0=1 的读地址字节，别在示波器上混淆）。
   **INT 引脚约束**：`P1.15`(INT1) **禁止开内部上拉**（传感器 INT1 是推挽输出，开 ≈13k 上拉会灌 ~250µA）；latched 中断**睡前必须清 latch**（读 INT1_SRC 或写 INT1_APP），否则 DETECT 常有效 → 唤醒风暴；睡前关掉其它脚的 sense（PORT/DETECT 是整端口 OR）。LIS2DW12 **禁用 single-data-conversion-on-demand 与 SLP_MODE_SEL=0**（该模式下 INT2 变时钟输入，而 INT2 悬空）；INT1/INT2 默认推挽输出，**不得加上拉**；I²C 上限 **400kHz**（4.7k 上拉只对 400kHz 成立）。
7. **GPS 软件复位**：`GPS_RST`(P0.02) 平时高阻输入；GPS 无响应时拉低 **≥100ms** 再释放。
8. **P0.13 拉低 = 3.3V_SW 断电**。深睡顺序：停 GPS → 关 OLED → P1.13 高阻 → 拉低 P0.13 → System OFF。
9. **WAKEUP 内部上拉漏电需实测**：手册未给阻值，姊妹型号同脚位标称「拉低到地 standby 约 600µA」，亮屏待机可能在 0.1~0.6mA 量级。
10. **待机策略**：屏灭时直接关 P0.13；GPS_EN 只在「3.3V_SW 必须开着」时用于单独关 GPS。
11. **电量采样**：`BAT_ADC_EN` 拉高后**至少等 90ms**（9τ，τ=R5‖R6·C9=10ms）再采，**采完立即拉低**；分压系数 **2.0**（200k/200k）；SAADC 用 0.6V 内参 / GAIN1_6。
    ⚠ **EN 为高时整条链常耗 ≈ 85µA**（R7 33µA + R4 42µA + 分压 10.5µA），是深睡预算 12µA 的 7 倍：
    - **进 System OFF / 深睡前必须显式拉低 BAT_ADC_EN**（nRF52 进 System OFF 后 GPIO 保持原配置）；
    - **采样周期 ≥30s**，或只在唤醒/上传前采样；1Hz 轮询会把深睡平均电流抬高 7.7µA。
12. **L76K 下电时序（不加泄放电阻）**：手册要求 VCC 掉到 **<100mV 并保持 ≥100ms** 才算完成掉电复位（L76K 硬件设计手册 §3.5）。本设计**不装泄放电阻**：
   - 日常 GPS 开关走 `GPS_EN`（WAKEUP，进 standby），**不断 3.3V_SW**，不涉及时序；
   - `3.3V_SW` 只在深睡时由 P0.13 切断，而深睡是分钟/小时级，轨上 ~11µF 靠器件漏电早已放完；
   - 若模块 LDO 自带输出放电（EN 可控时生效）则更快。
   **固件只需保证**：断 3.3V_SW 后至少 **≥1s** 再重新拉高（给电容放电留时间）。
   **兜底**：若实测发现"短睡后 GPS 未能干净复位"，可在 3.3V_SW 与 GND 间补一颗 100k（板上有空间，未预留焊盘）。
13. **外设实例互斥**：本设计要 **2×TWIM + 1×SPI**。nRF52840 的 `SPIM0/TWIM0` 与 `SPIM1/TWIM1` 是**同一实例**，所以 W25Q128 只能用 **SPIM2 或 SPIM3**：
    - **推荐 SPIM2**（8MHz → 1-1-1 约 1MB/s，日志够用），无额外勘误负担；
    - 若要 SPIM3 的 32MHz（约 4MB/s），必须开 **Errata 198 workaround**（TX 缓冲独占 RAM、传输中 CPU 不并发访问），且 **Errata 195**（disable 后仍持续耗流）与 12µA 深睡预算冲突；
    - **吞吐上限就是 ~4MB/s（SPIM3）/ ~1MB/s（SPIM2）**，且 **QSPI 物理不可用**（模块未引出 P0.19/P0.21/P0.23，且 SCK/CS 与 QSPI 固定脚冲突）——任何「25MB/s」的假设都不成立。v1 固件用的 `SPI3` 不能照搬。
14. **P0.13 的默认态**：System OFF 唤醒 = **复位**，P0.13 回到默认（高阻 → 模块默认导通）。固件必须在**启动最早期**把 P0.13 拉低，否则「睡时 3.3V_SW 已关」的状态无法跨唤醒保持。

## 8. 手册依据（关键条目）

1. **LIS2DW12**：SDO/SA0 内部上拉**不可关闭**（手册未给阻值；按 3.6V/2.5V 的 20.4k/30.4k 插值，3.3V 约 22kΩ），接 GND 会持续漏 ~140µA，而掉电电流仅 50nA → 接 3.3V_AON；退耦 **100nF + 10µF 紧贴 pin9**；`RES(pin7) 必须接 GND`；INT1/INT2 默认推挽输出，不可加上拉；LGA-12 2×2×0.7，pitch 0.5。
2. **LIS3DHTR**：LGA-16 3×3×1.0；**SA0 接 3.3V_AON = 0x19**（内部上拉不可关、手册未给阻值，接 GND 估计持续漏 ~150µA）；VDD 与 VDD_IO 均接 3.3V_AON。
3. **W25Q128JV**：DPD **1µA typ / 20µA max**、待机 10µA typ；`/CS` 上电期须跟随 VCC（手册建议加上拉）；**DPD 退出必须先发 `0xAB`**；上电默认待机且 DPD 跨 MCU 复位存活；`Q` 后缀 **QE 固定=1** → pin3/pin7 为 IO2/IO3；JV 系列无 QPI 指令；料号 `S` = SOIC-8 **208mil**。
4. **RT9080 / RT9080N**：`EN 不可悬空，可直连 VIN`；输出电容"有效 ≥1µF"，无最大限制；Iq 2µA typ / 4µA max；TSOT-23-5；dropout 0.31V@600mA。
   **pin4**：非 N 版为 NC（悬空或接 GND 均可），N 版为 SNS（**必须接 VOUT**，内部链路电流 550nA，SNS 电位 = 该料号标称 VOUT，接 VOUT 即分压比 1）。手册 DS9080-08 §15 Figure 1「Application with Sense Function」即无外部分压的固定输出图。**本设计统一接 VOUT，两种变体通用**。
5. **L76K**：18 脚 LCC 10.1×9.7×2.0 pitch 1.10；VCC 2.7–3.4V、连续 29mA、standby 20µA、backup 8µA；`WAKEUP` 低有效进 standby；`RESET_N` 内部上拉到 3.3V、禁止外加上拉；`V_BCKP` 不得晚于 VCC 上电；官方推荐 V_BCKP 4.7µF + 100nF + 33pF；无源天线直连不需隔直电容；`RESERVED` 必须悬空；`SET` 是星座选择。
6. **ProMicro（nologo）**：P0.13 低 → 关断 3.3V/VCC；BOOST 短接 → 充电 100→300mA（电池须 >500mAh）；板载 LDO 输出 3.3V；待机 ~20µA；电池接口 B+/B−。

### 9.4 低电量策略（补充约束）

3.3V_AON 在电池 &lt; ~3.32V 时随电池跌落，而 **W25Q128 最低工作电压 2.7V**：
电池低于 **2.75V** 时应禁止 flash 擦写并停止记录，避免半写损坏扇区。
**硬件级兜底**：QE=1 后 `/WP` 功能不存在，唯一可靠保护是用状态寄存器写保护 ——
`SR1.BP[2:0]=111`（全片保护）+ `SRP=1`（锁定 SR 不可再改），在电压跌落前先行写入，之后即使固件失控也擦不动。
