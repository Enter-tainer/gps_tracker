# 装配指南 / Assembly

从裸板到能记录轨迹的完整流程。**建议先通读一遍再动手**，LGA 封装（GPS / 传感器）拆焊很痛苦。

## 你需要准备

| 类别 | 清单 |
| --- | --- |
| 焊接 | 恒温烙铁、热风台、锡膏 / 0.6 mm 焊锡丝、助焊剂、镊子、放大镜或显微镜、吸锡带 |
| 测量 | 万用表、可调限流电源（3.0–4.2 V，限流 200 mA） |
| 物料 | [BOM](../../hardware/pcb/BOM.csv) 全部 13 项 + 21700 电芯（带保护板更安全） |
| 其他 | microSD 卡（建议 ≤ 32 GB，FAT32）、USB-C 数据线、3D 打印外壳、SWD 调试器（可选） |

## 1. 焊接顺序

原则：**先矮后高、先难后易、贴片先于插件/模块**。

1. **分压电阻** `R5`(200k) / `R6`(300k) —— 0805，最简单，先练手。
2. **LGA 传感器** `U4` BMP280、`U11` LIS3DHTR —— 锡膏 + 热风回流，注意 1 脚标记。
3. **卡座与按键** `U10` TF 卡座、`URST` / `UUSR` 轻触键、`CN2` 1.25 mm 座。
4. **GPS 模块** `U7`（18 pin LGA）—— 与传感器同样的回流工艺。
5. **陶瓷天线** `ANT` —— 焊盘较大，热风加热到焊锡铺开；**天线正下方与四周保持净空**。
6. **ProMicro nRF52840 模块** `C2` —— 26 个方形焊盘，模块竖贴，USB-C 口朝外壳开孔侧。
7. **21700 电池座** `U8` —— 焊盘大，建议先给焊盘上锡再放座子加热。

> 每焊完一类器件就用放大镜过一遍：LGA 器件最容易出现的失效是「引脚连锡」和「虚焊」，
> 症状分别是 3V3 短路、I2C 扫不到设备。

## 2. 上电前检查（必做）

用万用表二极管档 / 电阻档确认：

- `3V3` ↔ `GND`：**不能短路**（正常为 kΩ 级以上，视稳压器而定）
- `BAT` ↔ `GND`：**不能短路**，且应能测到分压电阻串联的约 500 kΩ
- `ADC` ↔ `GND`：约 300 kΩ；`ADC` ↔ `BAT`：约 200 kΩ
- 目视检查 `U4` / `U7` / `U11` 是否有连锡、立碑、错位

## 3. 首次上电

1. 限流电源设 **3.8 V / 200 mA**，接 `BAT`（或 `CN2` 的 BAT/GND）。
2. 上电后：
   - 电流应有明显跳变（模块启动），随后进入待机；
   - OLED 应亮起并显示 **Ferris 螃蟹 logo**，几秒后进入状态页；
   - 若电流瞬间打满或器件发热 —— **立即断电**，回到第 2 步查短路。
3. 万用表测 `3V3` 对地电压应在 3.3 V 左右；`GPSEN` 为高时 GPS 模块供电正常。

## 4. 刷入固件

两种方式，选一种即可。

### 方式 A：UF2（不需要调试器，推荐给第一次做的人）

```bash
# 在仓库根目录：构建固件 + 合并 SoftDevice，生成单个 UF2
cd tools
uv run gt uf2 build
# 产物：firmware/target/thumbv7em-none-eabihf/release/gps-tracker-combined.uf2
```

把模块切到 bootloader 模式（通常是**双击复位键**，会出现一个 U 盘），
把 `gps-tracker-combined.uf2` 拖进去，设备自动重启。

> 合并包里已经包含 S140 SoftDevice，**不需要单独刷协议栈**。
> 仓库不附带 Nordic 的 SoftDevice 十六进制文件（许可证限制），构建脚本会自动下载。

### 方式 B：probe-rs（需要 SWD 调试器）

```bash
cd firmware
cargo run --release          # .cargo/config.toml 里已配置 probe-rs runner
DEFMT_LOG=info cargo run --release   # 顺便看日志
```

## 5. 存储卡

- 格式化为 **FAT32**，插到位（注意 TF 卡座是推拉式还是自锁式，按实物）。
- 固件启动时挂载失败会在屏幕上提示，并可通过网页端查看系统信息确认。
- 轨迹文件是 `.gpz` 二进制（GPZ V1/V2），用网页端导出 GPX，或见 `docs/delta_compress_gpx.md`。

## 6. 装壳

见 [hardware/enclosure/README.md](../../hardware/enclosure/README.md)。要点：

- 全部焊接、通电自检通过**再**装壳；
- 按键要能从外壳键位按到，天线侧朝开口/薄壁；
- 电池极性确认无误再接入。

## 7. 自检清单

- [ ] 开机显示 logo → 状态页
- [ ] 手机/电脑 Chrome 打开网页端，能搜索到并连上设备（BLE）
- [ ] 网页端能看到系统信息（电量、SD 卡状态、固件版本）
- [ ] 室外或窗边 1–2 分钟内能定位（冷启动最长 90 s，见 `docs/state_spec.md`）
- [ ] 电量显示与万用表实测相差 < 0.1 V
- [ ] 带着走一段，网页端能列出并下载轨迹文件，导出 GPX 在地图上能对上
- [ ] 静置 60 s 后设备进入 S2（GPS 断电省电）

## 常见问题

| 现象 | 排查方向 |
| --- | --- |
| 屏幕不亮 | I2C 地址/接线、3V3 电压、OLED 模块是否 3.3V 版本 |
| 扫不到 BLE | 是否已刷入含 SoftDevice 的合并包；天线区域是否被金属挡住 |
| GPS 一直不定位 | `GPSEN` 是否拉高、模块是否焊好、天线净空、室内无法定位属正常 |
| 电量显示异常 | `R5`/`R6` 是否装反（200k 在 BAT 侧）、ADC 虚焊 |
| SD 卡挂载失败 | 卡是否 FAT32、卡座是否虚焊、卡是否被识别为 SDHC |
| 网页端点"USB 模式"后设备重启 | 正常：固件会写入 boot flag 后复位进入 U 盘模式 |
